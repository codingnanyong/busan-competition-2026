# 2025 Busan candidate-indicator exploratory analysis

## Purpose

COD-15 reproducibly checks distributions, missingness, outliers, correlations, and spatial
patterns in the 206-administrative-dong candidate profile. This stage evaluates data fitness; it
does not produce a composite IMD score or deprivation ranking.

## Run

After restoring the raw-data bundle, run:

```bash
docker compose run --rm jupyter python scripts/rebuild_processed.py
```

To rerun only the EDA stage:

```bash
docker compose run --rm jupyter python -m busan_imd.analysis.eda
```

Use `notebooks/01_candidate_profile_eda.ipynb` for interactive review. Generated CSV files are
written to the Git-ignored `outputs/eda/2025/` directory. Input and output hashes and core checks
are recorded in [EDA_REPORT_2025.json](../../data/manifests/EDA_REPORT_2025.json).

## Scope and completeness

- Canonical geography: 206 SGIS 2025 Busan administrative dongs in `EPSG:5179`
- Candidate profile: 206 rows and 100 columns
- Numeric EDA columns: 85
- Numeric provisional-scoring columns: 37
- Queen-contiguity links: 532

Provisional scoring columns have no missing values. Some mixed-date transit validation columns
are incomplete, and the elderly-living-alone reference-date field is missing for 20 dongs, so
those sources remain validation-only.

## Distribution and outlier findings

The 1.5-IQR rule produces 761 indicator-row flags across 85 numeric columns. This does not mean
that 411 rows are erroneous. Genuine central-city, peripheral, and island differences may create
extreme values, so the pipeline does not automatically delete or winsorize them.

`air_idw_station_count` is constant at four and is excluded from scoring. Zero-heavy facility
counts, including zero hospitals in 61 dongs and zero high schools in 111 dongs, remain observed
zeroes and will be compared with distance and service-area measures in COD-16.

## Correlation findings

Seven pairs have an absolute Pearson correlation of at least 0.8. The strongest original
scoring pairs remain inferred beneficiary households versus recipients (`0.982297`), clinic
versus pharmacy rates (`0.908014`), and establishments versus workplace workers (`0.879209`).
Highly correlated measures must not duplicate the same concept in the base score. The COD-16
handoff is recorded in
[EDA_INDICATOR_DECISIONS_2025.csv](../../data/EDA_INDICATOR_DECISIONS_2025.csv).

## Spatial findings

Interpolated air-quality variables have Moran's I values from `0.643912` to `0.770737`. These
values combine genuine exposure clustering with smoothing induced by the shared four-nearest-
station IDW method. The two-kilometre core-school service count also shows strong spatial
clustering (`0.682928`).

Six island or detached administrative dongs have no polygon-contiguity neighbor. They are excluded
from adjacency pairs for Moran's I and explicitly listed in the report; maps must still display
them rather than treating them as missing observations.

## Handoff to COD-16

- Conditional base candidates: inferred benefit-recipient rate, employment-opportunity proxy,
  nearest-school distance, hospital and clinic access, old-housing share, bus-stop access,
  heat-shelter access, and estimated PM2.5 exposure
- Sensitivity-only alternatives: establishment count, two-kilometre school service count,
  pharmacy access, CCTV, and NO2
- Excluded: constant station count, lineage strings, and redundant raw counts
- Safety domain: held from the base score until administrative-dong crime or accident data exists

Direction alignment and normalization belong to COD-16. COD-18 will test ranking stability under
alternative proxies, inferred values, and interpolated exposures.
