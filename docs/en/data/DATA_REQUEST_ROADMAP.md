# Data Request Roadmap

This roadmap identifies aggregated institutional data needed to replace open-data proxies. Requests target disclosure-controlled administrative-dong tables, not identifiable microdata.

| Priority | Domain | Requested aggregate | Minimum fields | Improvement |
|---:|---|---|---|---|
| 1 | Income | Income bands or benefit categories | Period, dong code, people/households, denominator | Broader income deprivation |
| 1 | Employment | Resident employment, unemployment, insurance | Dong code, age, status counts | Replace workplace-based proxies |
| 1 | Safety | Crime and incident counts by type | Dong code, type, period, count, denominator | Replace infrastructure proxies |
| 2 | Health | Standardized outcomes and service use | Dong code, standardized rate, period | Add resident outcomes |
| 2 | Education | Attainment, dropout, and outcomes | Dong code, age band, counts | Separate access and outcomes |
| 2 | Housing | Cost burden, minimum standard, common vacancy table | Dong code, household and dwelling counts | Combine physical and financial deprivation |
| 3 | Environment | High-resolution long-term exposures | Grid/coordinates, period, quality flags | Reduce spatial error |

Requests omit names, addresses, and personal identifiers; apply small-cell suppression; include denominators, deduplication rules, dates, and code versions; and record purpose, retention, and redistribution limits.

The stages are: open-data experimental model, institution-supported model, and independently reviewed operational policy reference. B-IMD must not be described as a statutory allocation formula before the operational stage.
