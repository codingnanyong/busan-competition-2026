# Limitations and Interpretation

Key limitations are proxy validity, unequal administrative-dong populations, boundary change, asynchronous reference periods, ecological fallacy, relative ranking, value judgements in weights, and systematic missingness from disclosure control.

The index must not be used to determine individual eligibility, treated as a statutory allocation formula, populated by repeating district values across dongs, or label proxy results as actual crime, unemployment, or disease rates. Rankings from releases with different inputs or methods are not interpreted as simple change.

Every publication accompanies results with direct/proxy labels, availability grades, reference periods, boundary version, missingness, exclusions, normalization, weights, sensitivity results, external validation, and a list of data still requiring institutional access.

## Current limitations from the COD-10 audit

- The Busan administrative-area page is internally inconsistent between totals of 205 and 206, so the reference geography is not frozen.
- Public income and vacancy files cover only selected districts with different dates and definitions. Uncovered dongs are never changed to zero and district values are never repeated.
- School, hospital, pharmacy, bus-stop, and heat-shelter locations are access proxies, not education, health, or income outcomes.
- Air-station interpolation error and coordinate-to-boundary join failure must be reported before those sources enter a composite.
- View-only sources and sources without verified derivative-redistribution terms remain validation-only.
