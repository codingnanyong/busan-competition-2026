# v0.8.0 — Demand-weighted transit and output layout

## Transit and reference metrics

- Strengthened the transit category as 60% stop supply, 20% demand-weighted route
  access, and 20% current headway and operating-hours service opportunity.
- Published living-population age and daytime pressure, consumer age and time-of-day
  mix, and 2023 boarding time bands as unscored diagnostic metrics.
- Recorded that newly granted collection access still does not put sources with the
  wrong spatial unit or as-of date into scored indicators.

## Dashboard and documentation layout

- Split the interactive map into feature HTML, CSS, and JS under
  `outputs/infographic/2025/interactive`, with the assembled file opened from that
  folder.
- Gated policy cards by the selected dong's category decision instead of repeating
  the same catalog package on every dong.
- Moved data-contract CSV files to `docs/data/tables/` so markdown and tables are
  separate.

## Repository standards

- Added an MIT license, code of conduct, contributing guide, and security policy.
- Tuned markdownlint so repeating Keep a Changelog headings are not false positives.

## Interpretation limits

- Results are an experimental relative screening of living conditions within Busan,
  not official statistics or a statutory funding rule.
- Estimated values and reference metrics require current administrative data and
  field review before policy use.
