# v0.3.0 — Reproducible data foundation and mirrored issues

## Analysis and data foundation

- Established a Docker-based Jupyter geospatial environment, Python package structure, tests, and quality checks.
- Added validated 2025 boundaries and codes for all 206 Busan administrative dongs.
- Added reproducible collectors and provenance manifests for population, transport, healthcare, environment, safety, housing, and income data.
- Added administrative-dong matching, missing-value and unit standardization, a data dictionary, and quality reports.

## Methodology and documentation

- Documented competition submission requirements and audited data availability.
- Defined Busan IMD domains and indicators, limitations, and the staged expansion model.
- Kept the core data and development documentation aligned in Korean and English.

## Collaboration and publishing

- Introduced one-to-one Linear/GitHub issue mirroring with PR validation and synchronized completion.
- Rewrote repository-relative documentation links to valid Wiki pages or source-file URLs during Wiki generation.
