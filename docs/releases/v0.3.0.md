# v0.3.0 — 재현 가능한 데이터 기반과 이슈 미러링

## 한국어

### 분석·데이터 기반

- Docker 기반 Jupyter 지리공간 분석 환경과 Python 패키지 구조를 구축했습니다.
- 2025년 부산 206개 행정동 경계와 기준코드를 검증 가능한 산출물로 추가했습니다.
- 인구·교통·의료·환경·안전·주거·소득 데이터를 수집하는 재현 가능한 수집기와 매니페스트를 추가했습니다.
- 행정동 코드 매칭, 결측·단위 표준화, 데이터 사전과 품질 리포트를 구축했습니다.

### 방법론·문서

- 공모전 제출 요구사항과 데이터 가용성 감사를 문서화했습니다.
- 부산형 IMD 영역·지표 명세, 한계, 단계별 확장 모델을 정리했습니다.
- 국문·영문 데이터 및 개발 문서를 함께 제공합니다.

### 협업·배포

- Linear와 GitHub Issues를 1:1로 연결하고 PR에서 두 이슈를 함께 완료하도록 정책과 CI를 강화했습니다.
- GitHub Wiki의 저장소 상대 링크를 올바른 Wiki 페이지 또는 원본 파일 URL로 변환합니다.

## English

- Established a Docker-based Jupyter environment, Python package structure, tests, and quality checks.
- Added validated 2025 boundaries and codes for all 206 Busan administrative dongs.
- Added reproducible public-data collectors, manifests, standardization, a data dictionary, and quality reports.
- Expanded competition, data-availability, and Busan IMD methodology documentation in Korean and English.
- Introduced mirrored Linear/GitHub issue governance and fixed repository-relative links in the generated Wiki.
