# v0.7.0 — 공개데이터 신뢰도 보강과 코드 구조화

## 데이터 신뢰도

- 학교알리미의 2025년 학교별 학생·교원 자료를 기존 NEIS 학교 좌표와 결합했습니다.
- 결합한 학교 자료를 행정동별 2km 교육공급 근거로 반영하고 출처와 산출 조건을 기록했습니다.
- 부산버스정보시스템의 현재 노선·배차·첫차·막차 자료는 별도로 수집하되, 기준시점이
  다른 2025년 주 점수를 덮어쓰지 않도록 검증자료로 분리했습니다.

## 정책 시각화

- 8개 하위 카테고리마다 관측 신호, 우선 대상, 실행 단계와 성과지표를 제공합니다.
- 부산시와 중앙부처의 공식 정책사례를 출처 링크와 함께 제시합니다.
- 사례는 그대로 복제할 정답이 아니라 행정동별 현장 확인 후 조정할 설계 참고자료로 표시합니다.
- 추정·대리·보정값은 사용 여부, 사유와 적용 한계를 행정동 상세 화면에서 확인할 수 있습니다.

## 코드 구조와 재현성

- `busan_imd`의 분석 모듈을 `analysis`, 데이터 처리 모듈을 `processing` 패키지로 정리했습니다.
- 인포그래픽 코드를 설정, 프로필 계산, 렌더링과 실행 파이프라인으로 분리했습니다.
- 재생성 스크립트, 노트북, 국문·영문 문서와 테스트 경로를 새 패키지 구조에 맞췄습니다.
- Ruff, GitGuardian과 전체 테스트 131개를 통과했습니다.

## 해석 시 유의사항

- 결과는 부산 내부의 상대적 생활여건을 탐색하는 실험적 평가이며 공식 통계나 예산 배분
  기준이 아닙니다.
- 추정값과 현재시점 검증자료는 최신 행정자료 및 현장 확인과 함께 사용해야 합니다.
