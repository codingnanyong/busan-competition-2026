# B-IMD 확장 모델

## 1단계 — 공개데이터형

목표는 현재 공개된 통계·공간자료로 재현 가능한 최소 실행모형을 만드는 것이다.

- 부산 전체 기준 행정동을 일관되게 포함
- 직접지표와 대리지표를 분리
- 점수·순위뿐 아니라 영역별 원인과 신뢰등급 공개
- 데이터·코드·실행환경과 릴리스 버전 고정

산출물에는 반드시 `실험적 지수`라는 지위를 표시한다.

## 2단계 — 기관협력형

부산시·구군과 관계기관의 비식별 행정동 집계자료로 핵심 대리지표를 교체한다.

- 소득·고용·건강·안전 직접지표 보강
- 최소 셀 억제와 개인정보보호 규칙 적용
- 공개형 모형과 순위·기여도 차이 분석
- 데이터 제공기관의 정의·품질 검토 반영

## 3단계 — 정책운영형

정기 갱신과 독립 검증을 갖춘 정책 참고지표로 발전시키는 장기 단계다.

- 공식 기준연도·경계·데이터 책임기관 지정
- 정기 갱신과 변경이력 관리
- 전문가·시민을 포함한 지표·가중치 검토
- 정책 투입 전후 효과평가와 외부 타당성 검증
- 오용 방지, 이의제기, 방법론 개정 절차 수립

## 단계 전환 게이트

| 전환 | 최소 조건 |
|---|---|
| 공개형 → 협력형 | 핵심 공백 데이터의 제공근거·집계수준·보호조치 합의 |
| 협력형 → 운영형 | 반복 갱신 가능성, 독립 검토, 정책효과 검증, 공식 책임주체 확보 |

공개형 모델이 완성됐다는 이유만으로 다음 단계의 정책 권한을 가정하지 않는다.
