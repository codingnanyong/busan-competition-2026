# 2025 행정동 취약유형 군집분석 검토

## 결론

COD-20의 군집분석은 **정책 유형으로 미채택**한다. 부산 206개 행정동의 6개 영역 점수에서
`k=2`~`6` K-means 후보를 검증했지만, 문서화한 분리도·재표본 안정성 게이트를 모두
통과한 후보가 없었다. 따라서 행정동에 군집 라벨을 부여하거나 COD-22 정책 매트릭스의
유형 근거로 사용하지 않는다.

이는 분석 실패가 아니라, 근거가 약한 유형을 결과물에 포함하지 않기 위한 품질 판정이다.
후속 정책과 시각화는 [상위 취약지역·기여도 분석](PRIORITY_AREAS_2025.md)의 연속형 영역·지표
기여도를 사용한다.

## 실행과 산출물

전체 처리 파이프라인은 다음 명령으로 재생성한다.

```bash
docker compose run --rm jupyter python scripts/rebuild_processed.py
```

COD-20 단계만 실행하려면 다음을 사용한다.

```bash
docker compose run --rm jupyter python -m busan_imd.cluster_analysis
```

생성되는 처리 산출물은 다음과 같다.

- `cluster_candidate_evaluation_2025.csv`: `k=2`~`6` 후보별 품질 지표와 게이트 판정
- `cluster_candidate_profiles_2025.csv`: 후보 군집 중심과 영역 평균을 담은 감사용 프로필
- `admin_dong_cluster_typology_2025.csv`: 채택 시에만 라벨을 담는 테이블. 2025 결과는
  미채택이므로 헤더만 있고 데이터 행은 없다.
- [CLUSTER_ANALYSIS_REPORT_2025.json](../data/manifests/CLUSTER_ANALYSIS_REPORT_2025.json):
  결정, 임계값, 입력·출력 체크섬과 재현 메타데이터

처리 CSV는 Git에서 제외되고 복원된 데이터 번들에서 재생성한다. 매니페스트와 방법론 문서는
Git에서 관리한다.

## 평가 설계

6개 영역 점수를 평균 0, 표준편차 1로 표준화한 후 고정 난수 `2025`, `n_init=50`인
K-means를 적용한다. 후보별로 다음을 평가한다.

- 실루엣 점수: 군집 내부 응집도와 군집 간 분리도
- Davies–Bouldin 지수와 Calinski–Harabasz 지수: 후보 간 보조 비교
- 최소 군집 크기: 지나치게 작은 정책 유형 방지
- bootstrap ARI: 행정동 206개를 100회 복원추출하고 전체 행정동을 다시 예측했을 때 기준
  라벨과의 Adjusted Rand Index
- 중심 구별 가능성: 각 군집이 적어도 한 영역에서 절대 표준화 중심값 `0.5` 이상인지 확인

프로젝트 채택 게이트는 다음과 같다. 이는 보편적 통계 기준이 아니라 이번 정책 유형화를 위한
보수적 운영 기준이다.

| 기준 | 통과 조건 |
|---|---:|
| 실루엣 | ≥ 0.25 |
| bootstrap ARI 중앙값 | ≥ 0.70 |
| bootstrap ARI 10백분위 | ≥ 0.50 |
| 최소 군집 크기 | ≥ 10개 동 |
| 구별 가능한 군집 비율 | 100% |

하나라도 미달하면 군집 수를 채택하지 않는다.

모든 후보는 군집 크기와 중심 구별 조건은 충족했지만 실루엣 게이트를 통과하지 못했다.
`k=2`는 ARI 10백분위 조건은 충족했으나 중앙값도 `0.70`에 미달했다. 이는 영역 점수가
몇 개의 선명하고 안정적인 집단보다 연속적인 취약성 구배에 가깝다는 증거다.

## 사용 규칙과 제한

- 후보 군집 프로필과 번호는 품질감사용이며 지역 유형명이나 정책 대상 라벨로 인용하지 않는다.
- COD-22와 COD-23은 군집 대신 종합점수, 영역·지표 기여도와 중앙값 대비 초과점수를 사용한다.
- K-means는 유클리드 거리와 구형 군집을 가정하며 공간 인접성을 직접 반영하지 않는다.
- 영역 점수에 포함된 소득·고용 등 대리지표의 한계는 군집 입력에도 그대로 전달된다.
- 향후 직접 행정자료가 추가되면 같은 게이트로 다시 평가하고, 이전 라벨과 단순 비교하지 않는다.

다음 단계 COD-21에서는 군집 라벨 없이 사회적 취약성과 부산 특화 환경노출의 중첩을 검토한다.
