# 2025 B-IMD 상위 취약지역·기여도 분석

## 목적과 범위

COD-19는 `B-IMD 2025` 1분위(부산 내 상대적으로 가장 취약한 약 10%) 21개 행정동을
우선지역으로 정의하고, 각 지역의 종합점수를 영역과 지표 단위로 분해한다. 이 분석은 순위를
정책 대상 선정의 단독 근거로 사용하지 않고, 어떤 공개 대리지표가 높은 점수에 기여했는지
설명하기 위한 진단 단계다.

## 실행과 산출물

전체 파이프라인은 다음 명령으로 재생성한다.

```bash
docker compose run --rm jupyter python scripts/rebuild_processed.py
```

COD-19 단계만 실행하려면 다음 명령을 사용한다.

```bash
docker compose run --rm jupyter python -m busan_imd.analysis.priority_areas
```

실행 결과는 다음 파일에 생성된다.

- `data/processed/scores/2025/busan_admin_dong_priority_areas_2025.csv`: 상위 21개 동의
  종합점수, 영역별 기여점수, 부산 중앙값 대비 초과점수와 대표 원인
- `data/processed/scores/2025/busan_admin_dong_priority_indicator_contributions_2025.csv`:
  상위 21개 동 × 9개 지표의 세부 기여도
- [PRIORITY_AREA_REPORT_2025.json](../data/manifests/PRIORITY_AREA_REPORT_2025.json):
  입력·출력 체크섬, 정의, 요약 결과

처리 CSV는 원천데이터와 같은 방식으로 Git에서 제외되며, 복원된 데이터 번들에서 위 명령으로
재생성한다. 매니페스트와 이 문서는 Git에서 관리한다.

## 계산 방법

지표 `i`가 영역 `d`에 속할 때 종합점수 기여점수는 다음과 같다.

```text
indicator_contribution_i
  = deprivation_percentile_i × within_domain_weight_i × composite_domain_weight_d
```

한 행정동의 9개 지표 기여점수 합은 공개된 `B-IMD` 종합점수와 일치한다. 영역 기여점수는
해당 영역 점수와 종합 영역 가중치의 곱이다.

높은 가중치 때문에 소득·고용이 기계적으로 크게 보이는 것을 구분하기 위해 대표 원인은
단순 기여점수가 아니라 `부산 전체 중앙값 대비 가중 초과점수`가 가장 큰 영역과 지표로
정의한다. 값이 양수이면 해당 지역의 취약점수가 부산 중앙값보다 종합점수를 더 높인다는
뜻이다. 동률은 이름 오름차순으로 결정해 결과를 재현 가능하게 유지한다.

21개 우선지역의 대표 영역은 고용 12개, 소득 9개다. 이는 실제 주민 실업이나 개인 소득을
직접 관측했다는 뜻이 아니다. 현재 공개형 기준선에서 소득은 구 단위 관측치를 행정동으로
추정한 기초생활수급 대리지표이고, 고용은 거주자 고용상태가 아니라 사업체 종사자 수를 이용한
지역 일자리 기회 대리지표다. 따라서 이 결과는 복지·고용 행정자료와 현장 확인의 우선순위를
정하는 탐색 신호로 사용해야 한다.

## 해석 규칙과 제한

- `1분위`는 부산 내부 상대순위이며 절대적 빈곤 판정이 아니다.
- 기여도는 산술적 점수 분해이며 인과효과나 정책효과의 크기가 아니다.
- 대표 원인 하나만으로 지역을 유형화하지 않고, 상세 CSV의 상위 지표와 음·양의 초과점수를
  함께 본다.
- 소득·고용 대리지표의 불확실성 때문에 주민 단위 행정자료 확보 시 우선 재검증한다.
- 작은 순위 차이는 과대해석하지 않고 [민감도 분석](SENSITIVITY_ANALYSIS_2025.md)의 순위
  변동과 함께 판단한다.

후속 [COD-20 군집분석 검토](CLUSTER_ANALYSIS_2025.md)는 이 기여도 벡터로 만든 `k=2`
군집이 품질 게이트를 통과함을 확인했다. 군집은 탐색적 정책 유형으로 사용하되 행정동별
연속형 기여도와 함께 해석한다.
