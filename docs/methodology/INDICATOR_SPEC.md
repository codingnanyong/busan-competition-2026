# B-IMD 지표 명세

## 목적과 지위

B-IMD는 공개데이터로 부산 행정동의 상대적 생활취약성을 탐색하는 실험적 복합지수다. 공식 통계, 개인의 박탈 판정 또는 법정 예산배분 기준이 아니다.

## 지표 명세 필수 필드

| 필드 | 설명 |
|---|---|
| 영역·지표명 | 측정 영역과 사람이 이해할 수 있는 이름 |
| 개념 정의 | 어떤 충족되지 않은 필요를 측정하는지 |
| 산식·단위 | 분자, 분모, 비율·거리·밀도 단위 |
| 측정 유형 | 직접지표·대리지표·맥락·검증지표 |
| 방향성 | 값이 클수록 박탈이 증가 또는 감소하는지 |
| 기준연도·공간 단위 | 관측기간과 원자료 지리 |
| 변환 | 공간결합, 연령표준화, 거리 계산 등 |
| 품질 | 가용성 등급, 결측률, 억제·마스킹 규칙 |
| 정규화 | 적용 방법과 선택 이유 |
| 영역 내 가중치 | 근거와 민감도 대안 |
| 출처·라이선스 | 데이터 카탈로그 ID와 이용조건 |
| 포함 결정 | 포함·보류·제외와 사유 |

## 초기 7개 영역

| 영역 | 측정하려는 개념 | 공개형 예시 | 향후 직접지표 예시 |
|---|---|---|---|
| 소득 | 필수 생활자원의 부족 | 급여 수급자 비율 | 소득구간·주거비 부담 |
| 고용 | 노동시장 비자발적 배제 | 사업체·종사자 변화 | 거주자 실업·불완전고용 |
| 교육 | 지식·기술·교육기회의 부족 | 저학력·시설 접근성 | 성인학력·학업중단·성과 |
| 건강 | 건강한 생활과 의료 이용의 제약 | 취약인구·의료 접근성 | 표준화 질환·사망·미충족 의료 |
| 안전 | 범죄·사고·재난으로부터의 위험 | 사고·화재·안전 인프라 | 유형별 범죄 피해 집계 |
| 주거·서비스 | 적정 주거와 필수서비스 접근 부족 | 노후도·빈집·교통·시설 접근성 | 최저주거·주거비 부담 |
| 생활환경 | 유해한 외부 생활환경 노출 | 침수·폭염·대기·녹지·경사 | 고해상도 장기 노출자료 |

## 계산 원칙

- COD-10 가용성 감사를 통과한 지표만 기본 모형에 포함한다.
- 가중치는 데이터 확보 전에 확정하지 않는다.
- 영국식, 동일가중, 부산 맥락 대안가중을 민감도 분석으로 비교한다.
- 영역에 포함되는 지표가 최소요건을 충족하지 못하면 임의 대체하지 않고 해당 영역을 보류한다.
- 포함 지표가 바뀌면 과거 릴리스 순위와 직접 비교하지 않는다.
- 점수·순위·10분위와 함께 영역별 기여도와 데이터 신뢰도를 제공한다.

## 2025 공개형 영역 점수 구현

COD-16 기본모형은 포함 지표를 평균순위 기반 0~100 백분위로 정규화하고, 모든 방향을
`높을수록 취약`으로 통일한다. 영역 내 지표는 동일가중 산술평균한다. 안전 영역은 직접
사건지표가 없어 보류하며, 영역 간 가중합은 COD-17, 대안 지표·가중치 민감도는 COD-18에서
다룬다. 상세 계약과 해석 제한은 [2025 영역 점수 계산](DOMAIN_SCORES_2025.md)에 기록한다.
영역 간 기준 가중치, 종합점수, 순위와 10분위는
[2025 B-IMD 종합지수](COMPOSITE_INDEX_2025.md)에 기록한다.
