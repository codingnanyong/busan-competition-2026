# 2025 B-IMD 영역 점수 계산

## 범위

COD-16은 2025년 부산 206개 행정동에 대해 후보지표의 취약 방향을 통일하고 0~100
백분위 점수로 정규화한 뒤 영역 내 점수를 계산한다. 값이 클수록 부산 안에서 상대적으로
더 취약하다는 뜻이다. 이 단계는 영역 간 가중합, 종합점수, 순위, 10분위를 만들지 않는다.
해당 작업은 COD-17 범위다.

## 실행

raw-data bundle을 복원한 저장소 루트에서 전체 파이프라인을 실행한다.

```bash
docker compose run --rm jupyter python scripts/rebuild_processed.py
```

영역 점수만 다시 생성하려면 다음을 실행한다.

```bash
docker compose run --rm jupyter python -m busan_imd.domain_scores
```

실행 계약은 [DOMAIN_SCORE_SPEC_2025.csv](../data/DOMAIN_SCORE_SPEC_2025.csv), 입력·출력
체크섬과 요약값은
[DOMAIN_SCORE_REPORT_2025.json](../data/manifests/DOMAIN_SCORE_REPORT_2025.json)에 기록한다.
가공 CSV는 Git에서 제외되는 `data/processed/scores/2025/`에 생성한다.

## 정규화

각 지표를 계약에 따라 `identity` 또는 `log1p`로 변환한 뒤 평균 순위를 계산한다. 동점은
평균 순위를 공유한다. 행정동 수를 \(N\), 평균 순위를 \(r_i\)라 하면 값이 클수록 취약한
지표의 점수는 다음과 같다.

```text
score_i = 100 * (r_i - 1) / (N - 1)
```

값이 클수록 접근성이 좋은 지표는 `100 - score_i`로 방향을 뒤집는다. 따라서 모든
정규화 지표와 영역 점수는 `높을수록 상대적 취약성이 큼`으로 해석한다. 백분위 순위는
극값의 크기에 덜 민감하지만 부산 내부의 상대 위치이므로 다른 연도나 지역과 절대 비교할
수 없다.

## 기본 영역 계약

| 영역 | 기본지표 | 방향 | 영역 내 가중치 |
|---|---|---|---:|
| 소득 | 추정 기초생활 수급자율 | 높을수록 취약 | 1.0 |
| 고용 | 사업장 종사자 수(`log1p`) | 낮을수록 취약 | 1.0 |
| 교육 | 핵심 학교 최근접 거리 | 높을수록 취약 | 1.0 |
| 건강 | 병원 수/인구, 의원 수/인구 | 낮을수록 취약 | 각 0.5 |
| 주거·서비스 | 노후주택 하한 비율, 버스정류소 수/인구 | 높음, 낮음 | 각 0.5 |
| 생활환경 | 무더위쉼터 수/인구, PM2.5 IDW | 낮음, 높음 | 각 0.5 |

한 영역에 둘 이상의 지표가 있으면 정규화 점수의 동일가중 산술평균을 사용한다. 영역 내
동일가중은 공개형 기본선이며, 대리지표 교체와 가중치 민감도는 COD-18에서 검증한다.

## 보류와 해석 제한

- 안전 영역은 행정동 단위 범죄·사고 직접지표가 없어 점수를 만들지 않는다. CCTV를
  사건위험으로 간주해 빈칸을 채우지 않는다.
- 소득 영역은 206개 동 모두 구 단위 관측 총계로부터 추정된 값이다.
- 고용 영역은 거주자 실업이 아니라 사업장 일자리 기회 대리다.
- 의료시설은 현재 인허가대장의 과거 시점 재구성값이다.
- 노후주택 비율은 억제 셀 영향을 받는 하한값이다.
- 대기질은 32개 측정소 IDW 보간의 평활 효과와 불확실성을 포함한다.
- 이번 점수로 공식 박탈 판정이나 예산배분 결정을 해서는 안 된다.
