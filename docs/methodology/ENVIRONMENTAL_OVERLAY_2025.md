# 2025 B-IMD 환경노출 오버레이

## 결론

COD-21은 2025년 부산 206개 행정동의 B-IMD와 연간 PM2.5·PM10 노출 추정치를
겹쳐 사회취약성과 대기오염의 이중부담 가능성을 선별했다. B-IMD 1분위 21개 동 가운데
미세먼지 노출 상위 25%에도 속한 곳은 **4개 동**이다. 이 결과는 대기환경과 사회취약성의
공간적 중첩을 확인하는 탐색 자료로 사용할 수 있지만, 항만이나 산업단지가 오염의
원인이라는 뜻은 아니다.

## 실행과 확인

COD-21 단계만 다시 만들려면 저장소 루트에서 다음 명령을 실행한다.

```bash
docker compose run --rm jupyter python -m busan_imd.environmental_overlay
```

- `data/processed/scores/2025/busan_admin_dong_environmental_overlay_2025.csv`: 206개 동의
  B-IMD, PM 노출 백분위·순위, 이중부담 판정
- [`notebooks/03_environmental_overlay_review.ipynb`](../../notebooks/03_environmental_overlay_review.ipynb):
  산점도, 행정동 지도, 이중부담 목록을 확인하는 대화형 시각화
- [ENVIRONMENTAL_OVERLAY_REPORT_2025.json](../data/manifests/ENVIRONMENTAL_OVERLAY_REPORT_2025.json):
  계산 규칙, 요약 통계, 대상 목록, 입력·출력 체크섬과 해석 한계

Jupyter가 켜져 있다면 `http://localhost:8888/lab/tree/notebooks/03_environmental_overlay_review.ipynb`
를 열고 `Run All Cells`를 선택한다. 노트북은 실행 위치가 저장소 내부인 한 프로젝트 루트를
자동으로 찾아 이동하며 추적 중인 보고서를 덮어쓰지 않는다.

## 방법

HEIS 2025 일평균 자료를 32개 공식좌표 측정소에서 최근접 4개소 IDW로 보간한 연간
PM2.5·PM10 값을 사용한다. 각 오염물질 값을 부산 206개 동 안에서 백분위 순위로 바꾸고
두 백분위의 산술평균을 `particulate_exposure_score_0_100`으로 정의한다. 점수가 높은 순으로
52개 동(206개의 25%를 올림)을 고노출로 고정하며, 동점은 행정동 코드 오름차순으로
결정한다.

이중부담은 다음 두 조건을 모두 충족할 때만 `true`다.

1. B-IMD 1분위(가장 취약한 10%)
2. 미세먼지 노출점수 상위 25%

임계값은 정책 대상의 확정선이 아니라 비교 가능한 탐색 선별 규칙이다. IDW 값은 개별
행정동의 직접 측정치가 아니며, 측정망 위치와 공간 평활화의 영향을 받는다.

## 2025 결과

| 구분 | 행정동 수 |
|---|---:|
| 이중부담 | 4 |
| B-IMD 우선지역만 해당 | 17 |
| 고노출만 해당 | 48 |
| 둘 다 아님 | 137 |

이중부담 선별 지역은 모라3동(사상구), 수정4동·수정1동(동구), 가락동(강서구)이다.
B-IMD 점수와 노출점수의 Spearman 상관은 `-0.126191`로 약한 음의 관계이며, 우선지역의
평균 노출점수(`42.810911`)도 그 밖의 지역(`51.086329`)보다 낮다. 따라서 부산 전체에서
사회취약성이 높을수록 미세먼지 노출이 일관되게 높다는 일반화는 지지되지 않는다. 다만
4개 동의 중첩은 후속 현장 검토와 세부 환경자료 결합의 우선 후보로 사용할 수 있다.

## 항만·산업단지 해석 제한

현재 데이터 카탈로그와 원본 번들에는 기준연도와 출처가 고정된 항만·산업단지 경계 또는
배출원 위치자료가 없다. 이 때문에 COD-21은 항만·산단 거리, 내부 여부, 배출량을 계산하지
않았으며 미세먼지 중첩을 특정 배출원에 귀속하지 않는다. 해당 분석을 확장하려면 다음을
먼저 확보해야 한다.

- 2025년 기준 항만구역과 산업단지 경계의 버전·좌표계·이용조건
- 사업장 또는 배출원별 위치와 기준기간이 일치하는 배출량
- 풍향·확산 또는 적절한 노출모형과 측정망 검증

자료가 확보되면 현재 206개 동 기준지리에 거리·면적 중첩·노출모형을 별도 변수로 추가하고,
현재의 대기오염 선별 결과와 분리하여 재검증한다.
