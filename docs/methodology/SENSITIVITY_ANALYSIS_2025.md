# 2025 B-IMD 가중치·결측 민감도 분석

## 목적

COD-18은 기준 종합지수의 순위가 영역 가중치와 영역점수 이용 가능성에 얼마나 의존하는지
검증한다. 결과는 기준 순위를 대체하지 않고, 상위 취약지역 해석에 필요한 불확실성 범위를
제공한다.

## 실행과 산출물

```bash
docker compose run --rm jupyter python -m busan_imd.analysis.sensitivity_analysis
```

시나리오 계약은
[SENSITIVITY_SCENARIOS_2025.csv](../data/SENSITIVITY_SCENARIOS_2025.csv), 요약과 체크섬은
[SENSITIVITY_ANALYSIS_REPORT_2025.json](../data/manifests/SENSITIVITY_ANALYSIS_REPORT_2025.json)에
기록한다. 행정동별 결과는 Git에서 제외되는
`data/processed/scores/2025/busan_admin_dong_sensitivity_2025.csv`에 생성된다.

## 시나리오

총 9개 시나리오를 같은 206개 행정동에 적용한다.

- 기준: 영국 IMD 공개 가중치를 현재 6개 영역에 재정규화
- 동일가중: 6개 영역을 각각 `1/6`로 반영
- 중앙값 대체: 실제 결측이 있을 때 영역별 중앙값으로 대체
- 체계적 영역 이용 불가 6개: 영역 하나씩 제외하고 남은 기준가중을 행별로 재정규화

현재 영역점수의 실제 결측은 `0`건이다. 따라서 중앙값 대체는 기준 결과와 완전히 같으며,
결측 처리의 실증적 우열을 주장할 수 없다. 영역 제외 시나리오는 실제 결측이 발생했다는
뜻이 아니라 특정 대리지표 묶음에 대한 의존도를 확인하는 스트레스 테스트다.

## 비교 지표

- Spearman 순위상관: `1`에 가까울수록 전체 순서가 안정적
- 평균·최대 절대 순위변동
- 기준과 같은 10분위에 남은 비율
- 기준 최상위 10분위 21개 동과의 중복률

`rank_change_from_baseline`이 양수면 기준보다 덜 취약한 순위로, 음수면 더 취약한 순위로
이동한 것이다. 동점은 종합지수와 동일하게 행정동 코드 오름차순으로 결정한다.

## 2025 결과

| 시나리오 | 순위상관 | 평균 절대변동 | 최대 변동 | 10분위 일치 | 최상위 10분위 중복 |
|---|---:|---:|---:|---:|---:|
| 동일가중 | 0.935706 | 15.98 | 65 | 41.75% | 85.71% |
| 소득 제외 | 0.816712 | 29.03 | 81 | 26.21% | 57.14% |
| 고용 제외 | 0.800421 | 28.61 | 91 | 28.16% | 66.67% |
| 교육 제외 | 0.940855 | 16.75 | 48 | 34.47% | 80.95% |
| 건강 제외 | 0.957656 | 13.26 | 46 | 46.12% | 85.71% |
| 주거·접근 제외 | 0.986311 | 7.18 | 41 | 66.99% | 90.48% |
| 생활환경 제외 | 0.985888 | 7.69 | 26 | 64.08% | 95.24% |

동일가중에서도 최상위 10분위의 18/21개 동은 유지되지만 전체 10분위 일치율은 41.75%다.
특히 소득 또는 고용 영역을 제외하면 최상위 집합과 전체 순위가 크게 바뀐다. 따라서
COD-19의 상위 취약지역 해석에서는 단일 순위만 제시하지 않고 동일가중 순위, 영역별 기여도,
최상위 집합 유지 여부를 함께 공개해야 한다.

## 제한과 결정

- 기준 결과는 유지하되 순위 자체를 정밀한 절대 서열로 해석하지 않는다.
- 소득은 전 행정동 추정치, 고용은 거주자 실업이 아닌 사업장 기회 대리지표이므로 두 영역의
  높은 영향도를 정책적 사실로 단정하지 않는다.
- 실제 영역점수 결측이 발생하는 새 자료가 추가되면 중앙값 대체 외에도 완전사례와 행별
  가중치 재정규화를 다시 비교한다.
- 부산 맥락 대안가중은 정책적 합의나 독립 근거 없이 임의로 만들지 않는다. 이번 분석은
  공개 기준가중과 투명한 동일가중을 비교 기준으로 사용한다.
