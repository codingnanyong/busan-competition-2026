# 한계 및 해석 원칙

## 핵심 한계

1. 대리지표: 시설 수나 수급 여부는 주민의 실제 건강·소득·안전을 완전히 측정하지 않는다.
2. 공간 단위: 부산 행정동은 인구 규모가 균일하지 않으며 경계 변경과 공간단위 수정 가능성이 있다.
3. 시간 불일치: 지표별 갱신 주기가 달라 동일 시점의 생활상태를 완전히 나타내지 못할 수 있다.
4. 생태학적 오류: 취약한 행정동의 모든 주민이 취약한 것은 아니며 개인 판정에 사용할 수 없다.
5. 상대순위: 1위가 2위보다 두 배 취약하다는 뜻이 아니고 부산 밖 지역과 절대수준을 비교하지 않는다.
6. 가중치: 영역 선택과 가중치는 가치판단을 포함하므로 대안 모형에서 순위 안정성을 검증해야 한다.
7. 데이터 억제: 소규모 셀 마스킹과 비공개는 특정 지역에서 체계적인 결측을 만들 수 있다.

## 금지되는 해석

- 개인·가구의 복지 자격 또는 위험도를 B-IMD로 판정
- 실험적 순위를 법정 낙후지역 또는 자동 예산배분 기준으로 사용
- 구 단위 값을 모든 행정동에 반복해 세밀한 차이가 존재하는 것처럼 표현
- 대리지표 결과를 실제 범죄율·실업률·질병률로 명명
- 방법론이나 입력 데이터가 다른 릴리스의 순위를 단순 증감으로 비교

## 공개 시 함께 제공할 항목

- 지표별 직접/대리 구분과 가용성 등급
- 기준연도, 행정동 코드 버전, 결측률과 제외 지역
- 정규화·가중치·민감도 분석 결과
- 외부 검증 결과와 설명되지 않는 불일치
- 비공개 또는 향후 요청이 필요한 데이터 목록
