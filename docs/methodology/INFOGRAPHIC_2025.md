# 2025 B-IMD 1페이지 지도·인포그래픽 초안

## 목적 적합성 판단

이 프로젝트의 목적은 부산 행정동별 상대적 생활취약성을 측정하고, 취약 원인을 설명해
지역별 정책 우선순위를 제안하는 것이다. COD-23 초안은 이 흐름을 한 페이지에서 다음과
같이 전달한다.

1. **어디가 상대적으로 취약한가**: 206개 행정동 B-IMD 지도와 1분위 21개 동
2. **각 동은 무엇이 취약한가**: 206개 동별 6개 영역 점수와 1·2순위 취약영역
3. **무엇을 개선할 것인가**: 주요 취약영역과 직접 연결한 개선 검토 방향
4. **어떤 지역이 먼저 보이는가**: 상위 10개 지역과 2개 탐색 유형
5. **어디까지 해석할 수 있는가**: 대리지표·민감도·인과·개인판정 금지 문구

따라서 공개데이터를 활용한 **문제지역 선별·원인 설명·정책 후보 연결**이라는 현재 목적에는
맞는다. 그러나 공식 정책지수 확정, 개인 자격 판정, 특정 정책의 효과 입증이라는 목적에는
맞지 않는다. 제출물에서는 “부산형 취약성 진단의 공개형 기준선”으로 표현하고, 기관
행정자료와 현장 검증으로 확장할 수 있다는 점을 제안 가치로 삼는다.

‘특화’는 취약성이 낮다는 사실만으로 정하지 않는다. 현재 결과는 상대 저취약 영역을
보전·연계 후보로 제공하지만, 실제 특화 방향은 산업·상권·관광·생활SOC 같은 지역자산
데이터를 추가한 뒤 판단한다.

PNG는 화면 미리보기용이며, 페이지 수와 제출 형식을 판정할 때는 PDF를 기준으로 한다.
HTML은 브라우저에서 바로 열 수 있고 외부 지도나 JavaScript 서버에 의존하지 않는다.
트리에서 큰 카테고리를 선택하면 지도 색이 하위 카테고리 가중합 점수로 바뀐다. 하위
카테고리를 선택하면 해당 세부 점수 분포로 지도가 전환된다. 이후 동을 선택하면 원지표,
취약 백분위, 가중치, 추정 사유, 신뢰도, 정책 게이트와 조건부 예시가 나타난다. 정책 카드는
분석 신호·우선 대상·실행 순서·성과지표·공식 참고사례·적용 주의점을 함께 표시한다. 점수
계약과 명지 회귀검증은 [2025 카테고리 평가](CATEGORY_ASSESSMENT_2025.md)를 따른다.

점수와 기준시점·공간단위가 다른 보조자료는 `점수 제외 참고지표`로 분리한다. 고용기회의
생활인구·업종 구성, 교육의 주변 학교 학생·교원, 의료의 AED 위치, 환경의 공원 위치와
대기 보간 불확실성, 안전의 구·군 사고통계와 부산 최근 5년 추이가 이에 해당한다. AED는
의료공급 세부 항목에서만, 공원은 환경 종합화면에서만 표시되어 다른 지도 레이어를 가리지
않는다.

## 재생성

Matplotlib과 Noto CJK 폰트가 고정된 Docker 이미지에서 실행한다.

```bash
docker compose build jupyter
docker compose run --rm jupyter python -m busan_imd.infographic
```

전체 가공 파이프라인의 마지막 단계에서도 자동 생성된다.

```bash
docker compose run --rm jupyter python scripts/rebuild_processed.py
```

## 포함한 핵심 결과

- 분석 단위: SGIS 2025 부산 행정동 206개
- 우선지역: B-IMD 1분위 21개 동
- 상위 3개: 모라3동, 초량6동, 반여3동
- 탐색 유형: 교육 중심 상대형 5개, 고용·소득형 16개
- 미세먼지 독립 이중부담: 가락동, 모라3동, 수정4동, 수정1동
- 동일가중 민감도: 상위 21개 중 18개 유지
- 주요 불확실성: 소득 추정 대리와 거주자 고용이 아닌 사업체 종사자 대리

## 디자인 원칙과 다음 수정

지도는 전체 B-IMD 점수를 연속 색상으로 표시하고 1분위 경계를 굵게, COD-21 이중부담을
청록 점으로 구분한다. 정책 카드는 COD-22의 양의 초과점수 게이트를 통과한 후보만 요약한다.
하단에는 비공식·실험 지위와 금지 해석을 항상 표시한다.

현재 파일은 `submission_draft`다. COD-24 보고서와 용어를 맞춘 뒤 제출 직전에 공식 파일명,
출처 표기 크기, PDF 1페이지, 인쇄 가독성을 다시 검수한다.
