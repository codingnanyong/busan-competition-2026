# 2025 B-IMD 1페이지 지도·인포그래픽 초안

## 목적 적합성 판단

이 프로젝트의 목적은 부산 행정동별 상대적 생활취약성을 측정하고, 취약 원인을 설명해
지역별 정책 우선순위를 제안하는 것이다. COD-23 초안은 이 흐름을 한 페이지에서 다음과
같이 전달한다.

1. **어디가 상대적으로 취약한가**: 206개 행정동 B-IMD 지도와 1분위 21개 동
2. **어떤 지역이 먼저 보이는가**: 상위 10개 지역과 점수
3. **무엇이 결과를 이끄는가**: 대표 원인 고용 12개·소득 9개
4. **어떻게 활용할 수 있는가**: 2개 탐색 유형과 정책 후보
5. **어디까지 해석할 수 있는가**: 대리지표·민감도·인과·개인판정 금지 문구

따라서 공개데이터를 활용한 **문제지역 선별·원인 설명·정책 후보 연결**이라는 현재 목적에는
맞는다. 그러나 공식 정책지수 확정, 개인 자격 판정, 특정 정책의 효과 입증이라는 목적에는
맞지 않는다. 제출물에서는 “부산형 취약성 진단의 공개형 기준선”으로 표현하고, 기관
행정자료와 현장 검증으로 확장할 수 있다는 점을 제안 가치로 삼는다.

## 재생성

Matplotlib과 Noto CJK 폰트가 고정된 Docker 이미지에서 실행한다.

```bash
docker compose build jupyter
docker compose run --rm jupyter python -m busan_imd.infographic
```

전체 가공 파이프라인의 마지막 단계에서도 자동 생성된다.

```bash
docker compose run --rm jupyter python scripts/rebuild_processed.py
```

## 포함한 핵심 결과

- 분석 단위: SGIS 2025 부산 행정동 206개
- 우선지역: B-IMD 1분위 21개 동
- 상위 3개: 모라3동, 초량6동, 반여3동
- 탐색 유형: 교육 중심 상대형 5개, 고용·소득형 16개
- 미세먼지 독립 이중부담: 가락동, 모라3동, 수정4동, 수정1동
- 동일가중 민감도: 상위 21개 중 18개 유지
- 주요 불확실성: 소득 추정 대리와 거주자 고용이 아닌 사업체 종사자 대리
