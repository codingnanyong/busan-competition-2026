# v0.4.0 — 부산형 IMD 분석 모델 기준선

## 분석 모델

- 2025년 부산 206개 행정동 후보지표의 분포, 이상치, 상관관계와 공간 자기상관을 검증했습니다.
- 9개 조건부 지표를 6개 영역의 0~100 상대박탈 점수로 정규화했습니다.
- 영국 IMD 공개 가중치를 현재 6개 영역에 재정규화해 B-IMD 종합점수, 순위와 10분위를 산출했습니다.
- 기준가중, 동일가중, 실제 결측 대체와 영역별 이용 불가를 포함한 9개 민감도 시나리오를 비교했습니다.

## 주요 결과

- 206개 행정동 모두 6개 영역 점수와 종합점수를 받았으며 실제 영역점수 결측은 0건입니다.
- B-IMD 종합점수 범위는 `20.956227`~`82.821838`, 중앙값은 `51.048498`입니다.
- 동일가중과 기준가중의 Spearman 순위상관은 `0.935706`이며, 최상위 10분위 21개 중 18개가 유지됩니다.
- 소득 또는 고용 영역을 제외할 때 순위 변동이 가장 커, 이 두 대리지표의 한계를 결과 해석에 함께 공개해야 합니다.

## 재현성과 협업

- 네트워크 없이 실행하는 processed-data 재생성 파이프라인에 EDA, 영역 점수, 종합지수와 민감도 분석을 연결했습니다.
- 국문·영문 방법론, 실행 계약 CSV와 체크섬 리포트를 함께 제공합니다.
- PR 병합 뒤 GitHub Issue와 Linear 완료 상태를 확인하고 Slack DM으로 결과를 전송하는 자동화를 추가했습니다.

## 제한

- 현재 결과는 부산 내부 상대 비교를 위한 실험적 공개데이터 모델이며 공식 통계나 법정 배분 기준이 아닙니다.
- 안전 영역은 직접 사건지표 부재로 보류됐고, 소득·고용을 포함한 조건부 대리지표의 불확실성이 남아 있습니다.
- 상위 취약지역의 영역별 원인 해석과 정책 연결은 다음 M4 단계에서 수행합니다.
