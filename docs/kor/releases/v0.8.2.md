# v0.8.2 — Linear 프로젝트 연동과 문서 언어 폴더

## 저장소 자동화

- Linear 이슈 생성 워크플로가 `COD` 팀과 공모전 프로젝트에 이슈를 붙입니다.
- Git 워크플로와 이슈 맵은 Secret·브랜치 안내를 반복하지 않고 연동 가이드를 가리킵니다.

## 문서 배치

- 국문 문서는 `docs/kor/`, 영문 문서는 `docs/eng/`에서 관리합니다.
- 감사표·명세 CSV와 체크섬 JSON은 언어에 묶이지 않도록 `docs/data/tables/`와
  `docs/data/manifests/`에 둡니다.

## 해석 시 유의사항

- 결과는 부산 내부의 상대적 생활여건을 탐색하는 실험적 평가이며 공식 통계나 예산 배분
  기준이 아닙니다.
