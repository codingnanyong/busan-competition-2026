# v1.0.0 — 공모전 제출본과 재현성 검수

## 제출 패키지

- Track 1 압축 구성에 맞춰 1페이지 시각화, 분석보고서 초안, 재배포 가능 파생표를
  `outputs/submission/2025/`에 모읍니다.
- 접수용 ZIP은 Hangul HWPX·PDF와 브라우저 대시보드를 포함합니다. 빈 서식과 원천
  파일은 넣지 않습니다.
- 2026-08-31 공모전 서류 접수를 마쳤습니다.

## 재현성

- 시각화 1페이지, 출처 42건, 라이선스·수집방법, 비밀값 부재를 검사합니다.
- 원천 번들은 Drive `raw-data/2025/`에만 두고, 전체 재생성은
  `scripts/rebuild_processed.py`를 따릅니다.

## 해석 시 유의사항

- 결과는 부산 내부의 상대적 생활여건을 탐색하는 실험적 평가이며 공식 통계나 예산 배분
  기준이 아닙니다.
