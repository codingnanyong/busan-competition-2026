# v0.5.0 — 상위 취약지역과 기여도 해석

## 우선지역 분석

- B-IMD 1분위에 속한 부산 21개 행정동을 우선지역으로 정의했습니다.
- 각 지역의 종합점수를 6개 영역과 9개 지표의 가중 기여점수로 분해했습니다.
- 부산 전체 중앙값 대비 가중 초과점수가 가장 큰 영역과 지표를 지역별 대표 원인으로
  기록했습니다.
- 영역·지표 기여점수의 합이 공개된 B-IMD 종합점수와 일치하도록 자동 검증합니다.

## 주요 결과

- 상위 3개 지역은 사상구 모라3동, 동구 초량6동, 해운대구 반여3동입니다.
- 21개 우선지역 중 고용이 대표 영역인 곳은 12개, 소득은 9개입니다.
- 우선지역 프로필 21행과 지표별 기여도 189행을 재현 가능한 처리 산출물로 제공합니다.

## 재현성과 문서

- 네트워크 없이 실행하는 전체 재생성 파이프라인에 우선지역 분석 단계를 연결했습니다.
- 입력·출력 체크섬, 계산 정의와 상위 10개 지역 요약을 매니페스트에 기록했습니다.
- 국문·영문 방법론에 실행 방법, 기여도 계산식, 해석 규칙과 제한을 문서화했습니다.
- Ruff와 전체 테스트 101개를 통과했습니다.

## 제한

- 우선지역은 부산 내부 상대순위이며 절대적 빈곤 판정이나 법정 배분 기준이 아닙니다.
- 기여도는 산술적 점수 분해이지 인과효과 또는 정책효과의 크기가 아닙니다.
- 대표 영역을 주도한 소득·고용 값은 각각 추정 기초생활수급과 사업체 종사자 기반
  대리지표이므로, 행정자료와 현장 확인을 거쳐야 합니다.
- 지도와 1페이지 인포그래픽은 후속 COD-23 범위입니다.
