# v0.6.0 — 행정동 생활여건 진단과 정책 시각화

## 분석 범위

- 부산 206개 행정동의 취약 특성이 뚜렷한 몇 개 유형으로 나뉘는지 군집분석으로 검토했습니다.
- 다중결핍과 대기오염 노출을 결합해 환경 이중부담이 큰 지역을 별도로 확인했습니다.
- 지역별 취약 원인을 정책 우선순위와 실행 예시로 연결하는 매트릭스를 만들었습니다.
- 3개 큰 카테고리, 8개 하위 카테고리와 13개 평가지표를 트리에서 선택해 비교할 수 있는
  행정동 생활여건 지도를 제공합니다.

## 시각화와 정책 해석

- 지도에서 큰 카테고리와 하위 카테고리의 점수 분포를 전환해 볼 수 있습니다.
- 행정동을 선택하면 점수에 사용한 평가지표, 데이터 근거, 추정 사유와 조건부 정책 예시가
  함께 표시됩니다.
- 큰 카테고리 결과는 소속 하위 카테고리의 평가를 표시된 비중으로 종합한 값입니다.
- 화면 제목과 설명은 `부산 행정동 생활여건 진단: 취약 요인과 정책 방향`으로 정리하고,
  의미가 모호했던 `생활서비스·정주`를 `생활 인프라·주거`로 바꿨습니다.

## 데이터 신뢰도

- 직접 관측값과 추정·대리·보간값을 구분하고, 추정값에는 사용 사유를 행 단위로 기록했습니다.
- 명지권과 같은 신규 개발지역의 교육시설 변화가 과도한 취약 판정으로 이어지지 않도록
  보정 조건과 한계를 명시했습니다.
- 결과는 정책 후보를 탐색하는 상대평가이며, 공식 통계나 예산 배분 기준이 아닙니다.
- 추정값이 포함된 결과는 최신 행정자료와 현장 확인을 거쳐 정책 판단에 사용해야 합니다.

## 재현성과 품질

- 네트워크 없이 실행하는 전체 재생성 파이프라인을 군집, 환경, 정책과 시각화 단계까지
  확장했습니다.
- 결과 CSV, HTML 지도, 1페이지 PDF·PNG·SVG와 계산 매니페스트를 함께 제공합니다.
- Ruff, Pyright, cspell과 전체 테스트 129개를 통과했습니다.
