# v0.8.1 — 배차 결측 처리와 병합 후 정책 검사

## 대중교통 점수

- 배차·운행시간이 모두 없는 동의 서비스 기회를 0이 아니라 결측으로 남깁니다.
- 관측된 동만 백분위로 비교하고, 결측 동의 20% 가중치는 카테고리 합산과 정책
  게이트에서 제외합니다.
- `--route-stops-csv` 상위 폴더를 만들고, 2023 승하차 검증 해시에 현재 노선 정류장과
  정류소 좌표를 포함합니다.

## 저장소 자동화

- 병합된 PR이 Linear 연동으로 다시 수정되어도, 이미 닫힌 GitHub Issue를 열어 두라고
  요구하지 않습니다. 이 재실행이 실패 알림을 만들던 경로입니다.

## 해석 시 유의사항

- 결과는 부산 내부의 상대적 생활여건을 탐색하는 실험적 평가이며 공식 통계나 예산 배분
  기준이 아닙니다.
