# v0.8.0 — 수요가중 대중교통과 산출물 구조 정리

## 대중교통과 참고지표

- 대중교통 카테고리를 정류장 공급 60%, 수요가중 노선 접근 20%, 현재 배차·운행시간
  기반 서비스 기회 20%로 보강했습니다.
- 생활인구 연령·주간압력, 소비 연령·시간대, 2023 승하차 시간대는 점수에 넣지 않고
  진단용 참고지표로만 공개합니다.
- 수집 권한이 열린 뒤에도 공간단위·기준일이 다른 자료는 점수에 넣지 않는다는 재검토를
  사용 대장에 기록했습니다.

## 대시보드와 문서 구조

- 대화형 지도의 HTML·CSS·JS를 `outputs/infographic/2025/interactive`에서 기능별로
  나누고, 조립 결과는 같은 폴더의 HTML로 엽니다.
- 정책 카드는 모든 동에 같은 목록을 붙이지 않고, 선택한 동의 카테고리 판정 뒤에만
  검토 후보·모니터링·상대 저취약으로 구분합니다.
- 데이터 계약 CSV를 `docs/data/tables/`로 옮겨 마크다운 문서와 표를 구분합니다.

## 저장소 기준

- MIT 라이선스, 행동 강령, 기여 안내, 보안 정책을 추가했습니다.
- Keep a Changelog 반복 제목이 오경보가 되지 않도록 markdownlint 규칙을 맞췄습니다.

## 해석 시 유의사항

- 결과는 부산 내부의 상대적 생활여건을 탐색하는 실험적 평가이며 공식 통계나 예산 배분
  기준이 아닙니다.
- 추정값과 참고지표는 최신 행정자료 및 현장 확인과 함께 사용해야 합니다.
