# 2025년 행정동별 기초생활보장 수급자 추정

## 결론

부산 206개 행정동의 2025년 기초생활보장 수급자·수급가구 후보 지표를 생성했다.
다만 구·군 합계만 실제 2025년 12월 관측값이며, **행정동 값은 모두 추정값**이다.

- 부산 전체 관측 합계: 수급권자 256,393명, 수급가구 194,722가구
- 공간 범위: 부산 16개 구·군, 206개 행정동
- 결과: `data/processed/candidates/2025/basic_livelihood_inferred_2025.csv`
- 근거 및 검증: `docs/data/manifests/BASIC_LIVELIHOOD_INFERENCE_MANIFEST_2025.json`
- 표준 프로필 열:
  `basic_livelihood_recipients_per_1000_population_2025_inferred`

## 산출 방법

1. 공공데이터의 2025년 12월 구·군별 맞춤형급여 수급권자·가구 합계를 고정한다.
2. 북구·동구·금정구·남구·해운대구·수영구는 공개된 동별 수급 분포를 가중치로 쓴다.
3. 나머지 10개 구·군은 독거노인 비율, 30년 이상 주택 비율, 인구 대비 가구 압력을
   사용한 릿지 상대위험 모형으로 동별 가중치를 만든다.
4. 최대잔여법으로 정수화하여 각 구·군의 수급권자·가구 합계가 원자료와 정확히
   일치하도록 한다.

모형은 6개 구 86개 동의 공개 분포로 학습했고, 학습자료 내 결정계수는 0.562814다.
이 수치는 추정 분포의 설명력을 나타낼 뿐 실제 동별 수급자 수의 정확도를 보장하지 않는다.

## 사용 제한

- `inferred`가 붙은 열을 관측 통계로 표기하지 않는다.
- 소득 영역의 임시 대리지표로만 사용하고, 포함·제외 민감도 분석을 함께 제시한다.
- 2025-12-31 동일 정의의 부산 전역 행정동 원자료가 확보되면 추정치를 폐기하고 교체한다.
- 순위나 특정 동의 정책 판단에는 원자료 확인 없이 단독 사용하지 않는다.

## 결과 파일의 출처 표시 열

모든 행은 다음 열로 추정 상태와 데이터 계보를 공개한다.

- `value_status`: 항상 `inferred_not_observed`
- `district_total_source_dataset_id`: 2025년 12월 구·군 합계 원자료
- `inference_pattern_source_dataset_ids`: 해당 동 분포 또는 모형 학습에 사용한 자료
- `inference_feature_source_dataset_ids`: 모형 배분에 사용한 설명변수 원자료
- `inference_basis`: 관측 동 분포 사용 또는 상대위험 모형 사용 여부
- `inference_quality_tier`: 관측 분포 재배분 `C1`, 모형 분포 재배분 `C2`

`C1`과 `C2` 모두 추정치다. `C1`도 서로 다른 기준일 또는 급여 세부유형의 동별 분포를
2025년 12월 구·군 합계에 맞춰 재배분했으므로 관측된 2025년 12월 동별 수급자 수로
해석하지 않는다.
