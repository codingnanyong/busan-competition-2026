# 기관 데이터 요청 문안

## 공통 요청문

### 제목

부산형 다중박탈지수 연구를 위한 행정동 비식별 집계 및 공간자료 요청

### 본문

부산광역시 행정동별 생활 취약성을 소득, 고용, 교육, 건강, 안전, 주거·서비스 접근성,
생활환경 영역으로 분석하는 공모전 연구를 수행하고 있습니다. 개인 식별정보가 아닌
행정동 집계 또는 공공시설 공간자료를 요청드립니다.

2025년 연간 완결자료 또는 2025년 12월 31일 기준 스냅샷을 우선 제공해 주시기 바랍니다.
가능하면 2026년 1월 1일~7월 31일 누계도 변화 방향 확인용 보조자료로 함께 요청드립니다.
두 기간은 서로 합치지 않으며 주 지수와 보조 검증으로 구분합니다.

공통으로 다음 메타데이터도 요청드립니다.

- 데이터 기준기간·추출일·담당 부서
- 행정동 코드 체계와 기준일
- 지표 정의, 분모, 중복 제거 규칙과 결측 표현 방식
- 0건, 미수집, 비공개, 해당 없음의 구분
- 소수 셀 마스킹 기준
- 연구 결과의 표·지도·지수 및 코드 공개 허용 범위

CSV, XLSX, GeoJSON 또는 SHP 형식을 우선 요청하며 이름, 주민등록번호, 개인 주소·전화번호,
개별 사건 서술 등 개인 식별자료는 요청하지 않습니다.

## AED 전용 추가문구

현재 공개 API는 조회 시점의 목록만 제공하고 기준일·설치일·철거일 필드가 없어 과거
스냅샷을 재현할 수 없습니다. 따라서 2025-12-31과 2026-07-31 당시 보관본을 각각
요청드립니다. 제공이 어렵다면 해당 기준일의 구·군 또는 행정동별 설치대수와 운영 가능
대수 집계표, 데이터 정의 및 불가 사유를 요청드립니다.

## 제공 불가 회신 시 기록할 내용

- 제공 불가 사유와 적용 법령·정책
- 제공 가능한 최소 공간단위와 가장 가까운 기준기간
- 열람만 가능한지, 비공개 원본으로 집계분석만 가능한지
- 추후 공개 예정일 또는 대체 공개자료
