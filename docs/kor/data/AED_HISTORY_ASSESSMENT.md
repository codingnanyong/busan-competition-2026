# 부산 AED 과거자료 가용성 검토

## 결론

[부산광역시 자동심장충격기현황정보서비스](https://www.data.go.kr/data/15095264/openapi.do)는
현재 설치 목록 조회 API이며 2025년 기준 스냅샷을 선택하거나 복원할 수 없다. 2026-08-12에
수집한 1,079건은 출처 감사와 현재 시설 맥락에는 사용할 수 있지만 2025년 또는
2026-07-31 기준 지수 입력값으로 표시하지 않는다.

공공데이터포털에 표시된 `수정일 2025-07-29`는 API 목록의 메타데이터 수정일이다. 데이터
기준일이나 개별 AED 관측일이 아니므로 이 날짜를 전체 레코드의 기준일로 대체하지 않는다.

## 확인한 API 계약과 응답

- 엔드포인트: `https://apis.data.go.kr/6260000/BusanAedsService/getAedsList`
- 요청변수: 인증키, 페이지 번호, 페이지당 건수, 결과 형식
- 과거 조회변수: 없음
- 실제 응답 필드: `model_nm`, `addrs`, `product_nm`, `biz_tel`, `geom`
- 기준일·설치일·철거일·등록일·수정일 필드: 없음
- 2026-08-12 수집 건수: 1,079건

현재 목록에서 2025년에 이미 설치돼 있었을 장비를 추정하는 것도 허용하지 않는다. 설치일이
없고, 2025년 이후 철거·이전된 장비는 현재 목록에서 사라지므로 과거 분포를 재구성할 수
없기 때문이다.

## 확보 경로

공공데이터포털의 `공공데이터 제공신청` 또는 부산광역시 빅데이터과·보건 관련 부서에 다음
두 기준일의 보관본을 요청한다.

1. 2025-12-31 기준 부산광역시 AED 설치현황
2. 2026-07-31 기준 부산광역시 AED 설치현황

요청 형식은 CSV, XLSX, GeoJSON 또는 SHP 중 하나로 하고 다음 필드를 포함한다.

| 필드 | 필요 이유 |
|---|---|
| 데이터 기준일 | 2025 연간값과 2026 컷오프 판정 |
| 장비 비식별 관리번호 | 동일 장비 중복 제거와 두 시점 변화 검증 |
| 설치기관명·설치장소 | 시설 유형과 실제 접근 위치 확인 |
| 도로명주소·위도·경도·좌표계 | 2025 행정동 경계 공간결합 |
| 설치일·철거일·이전일 | 각 기준일에 실제 존재한 장비 판정 |
| 이용 가능 요일·시간 | 단순 설치 수와 실질 접근성 구분 |
| 점검상태·최근 점검일 | 사용 불가능한 장비 제외 |
| 자료 생성부서·정의·중복 제거 규칙 | 재현성과 품질 검증 |

개인 담당자 이름이나 개인 연락처는 요청하지 않는다. 공개 시설 전화번호가 포함되더라도
분석용 파생자료에는 필요하지 않으면 제거한다.

## 수용 기준

- 기준일이 명시되고 2026-07-31을 넘지 않는다.
- 부산 전역을 동일한 정의로 포함한다.
- 좌표 또는 행정동 코드로 2025 SGIS 경계에 재현 가능하게 결합할 수 있다.
- 중복·철거·점검중 상태를 구분할 수 있다.
- 원본 분석과 집계 지도·지수 파생물 공개 허용 범위를 확인한다.

조건을 충족하지 못하면 AED는 종합지수 직접지표가 아니라 현재 시설 분포를 설명하는 참고
자료로만 유지한다.
