# 데이터 기준기간 정책

## 확정 결정

- 주 분석 기준연도: **2025년 연간자료**
- 수집 컷오프: **2026-07-31**
- 공간 기준: **SGIS 2025년 부산 행정동 206개**
- 원칙: 2025년 연간자료로 지수를 구성하고, 2026년 1~7월 자료는 보조 검증과 변화 방향
  확인에만 사용한다.

공모전의 주 점수와 순위는 2025년 완결자료에 초점을 맞춘다. 2026년 부분연도 누계와
스냅샷은 2025년 값과 같은 열에 혼합하거나 주 점수의 결측 대체값으로 사용하지 않는다.

## 지표 선택 규칙

1. 2025-01-01~2025-12-31 완결자료 또는 2025-12-31 기준 스냅샷을 최우선한다.
2. 2025년 자료가 없으면 가장 가까운 이전 완결연도를 대체자료로 사용하고 `lag_years`를
   기록한다.
3. 2026년 1~7월 자료는 `supplemental_validation`으로 분류하고 주 지수에는 넣지 않는다.
4. 같은 지표의 모든 행정동에는 동일한 시작일과 종료일을 적용한다. 2026년 1~7월 누계와
   2025년 연간값을 같은 열에서 비교하지 않는다.
5. 최신 자료가 없으면 가장 가까운 과거 완결기간을 사용하고 실제 `reference_period`,
   기간 유형(`annual`, `partial_year`, `snapshot`)과 시차(`lag_months` 또는 `lag_years`)를
   기록한다.
6. `published_at`, `reference_period`, `retrieved_at`을 구분하며 게시일만으로 최신성을
   판단하지 않는다.
7. 여러 해 평균은 2025-12-31 이하에서 끝나는 고정 구간만 주 분석에 허용하고 구간을
   명시한다.
8. 기관 자료 요청은 2025년 연간값 또는 2025-12-31 기준 보관본을 필수로 요청하고,
   가능하면 2026년 1~7월 자료를 보조자료로 추가 요청한다.

## 공개 규칙

결과 표와 지도에는 공간 기준연도와 함께 지표별 관측기간과 기간 유형을 표시한다. 오래된
과거 대체자료에는 시차 경고를 붙인다. 2026년 부분연도 자료는 보조 검증으로 명시하고
주 점수와 분리하여 민감도 분석에서만 확인한다. 수집일은 출처 추적용이며 관측기간을
대신하지 않는다.
