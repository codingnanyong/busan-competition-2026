# 2025 부산 행정동 후보지표 탐색 분석

## 목적

COD-15는 2025년 부산 206개 행정동 후보 프로필의 분포, 결측, 이상치, 상관관계와
공간 패턴을 재현 가능하게 점검한다. 이 단계는 데이터 적합성을 판단하는 과정이며
종합 IMD 점수나 취약지역 순위를 만들지 않는다.

## 실행

raw-data bundle을 복원한 뒤 저장소 루트에서 다음을 실행한다.

```bash
docker compose run --rm jupyter python scripts/rebuild_processed.py
```

전체 재생성 없이 EDA만 다시 실행하려면 다음 명령을 사용한다.

```bash
docker compose run --rm jupyter python -m busan_imd.analysis.eda
```

대화형 검토는 `notebooks/01_candidate_profile_eda.ipynb`를 사용한다. 코드가 생성하는
CSV는 `outputs/eda/2025/`에 저장되며 Git에서 제외된다. 입력·출력 체크섬과 핵심 검증값은
[EDA_REPORT_2025.json](../../data/manifests/EDA_REPORT_2025.json)에 기록한다.

## 입력과 범위

- 기준 공간: 2025년 SGIS 부산 행정동 206개, `EPSG:5179`
- 후보 프로필: 206행, 100열
- 수치 분석 컬럼: 85개
- 잠정 점수 후보 수치 컬럼: 37개
- 공간 인접관계: queen contiguity 532개

잠정 점수 후보 수치 컬럼에는 결측이 없다. 혼합시점 대중교통 검증 컬럼 일부와 비수치
검증 컬럼인 독거노인 기준일(20개 동)은 비어 있으므로 해당 자료는 계속 검증 전용으로 둔다.

## 분포와 이상치

IQR 1.5배 규칙으로 85개 수치 컬럼 전체에서 761개의 이상치 플래그를 확인했다. 이는
411개 행이 잘못됐다는 뜻이 아니라 지표-행 조합별 플래그 합계다. 부산의 중심지·외곽·섬
지역 차이가 실제 극값을 만들 수 있으므로 자동 삭제하거나 winsorize하지 않는다.

`air_idw_station_count`는 모든 동에서 4로 일정하므로 점수 입력에서 제외한다. 병원 61개
동, 고등학교 111개 동처럼 시설 개수 0이 많은 컬럼은 관측 0으로 유지하되, COD-16에서
거리·서비스권 지표와 비교한다.

## 상관관계

절대 Pearson 상관계수 0.8 이상인 쌍은 7개다.

| 지표 A | 지표 B | 상관계수 | 판단 |
|---|---|---:|---|
| 기초생활 수급 가구 추정 | 기초생활 수급자 추정 | 0.982297 | 인구 대비 수급자율 하나를 우선 사용 |
| 의원 수/인구 | 약국 수/인구 | 0.908014 | 기본모형에 동시에 넣지 않음 |
| 사업체 수 | 종사자 수 | 0.879209 | 고용기회 대리 하나를 기본으로 두고 대안 비교 |
| 의원 수 | 약국 수 | 0.834289 | 원시 개수 중복 투입 금지 |
| 중학교 수 | 전체 학교 수 | 0.806104 | 거리 또는 서비스권 중심으로 단순화 |

고상관 지표를 함께 넣으면 같은 현상을 중복 가중할 수 있으므로
[EDA_INDICATOR_DECISIONS_2025.csv](../../data/tables/EDA_INDICATOR_DECISIONS_2025.csv)의 기본·민감도 구분을
COD-16 입력 계약으로 사용한다.

## 공간 패턴

대기질 보간값의 Moran's I가 `0.643912~0.770737`로 가장 높다. 이 값은 실제 오염의
공간 군집뿐 아니라 동일한 32개 측정소에서 최근접 4개 IDW로 보간한 방법의 평활 효과도
포함한다. 교육시설 2km 서비스권도 `0.682928`로 강한 공간 군집을 보였다.

공간 인접성이 없는 6개 도서·분리 행정동은 Moran's I 계산의 인접쌍에서 제외하고 보고서에
코드를 공개한다. 결과 지도에서는 이 지역을 결측으로 지우지 않고 별도 표시해야 한다.

## COD-16 전달 결정

- 조건부 기본 후보: 추정 수급자율, 고용기회 대리, 학교 최근접 거리, 병원·의원 접근성,
  노후주택 비율, 버스정류소 접근성, 무더위쉼터 접근성, PM2.5 노출 추정
- 민감도 전용: 사업체 대안, 학교 2km 서비스권, 약국 접근성, CCTV, NO2
- 제외: 상수인 `air_idw_station_count`, 계보용 문자열, 중복 원시 개수
- 안전 영역: 행정동 범죄·사고 직접자료가 없어 기본 점수는 계속 보류

이 결정은 최종 포함 확정이 아니다. 방향성 통일·정규화와 영역 점수 계산은 COD-16에서
수행하고, 추정값·보간값·대리지표 교체에 따른 순위 안정성은 COD-18에서 검증한다.
