# 프로젝트 계획

## 목표

부산 행정동별 생활 취약성을 소득, 고용, 교육, 건강, 안전, 주거·서비스 접근성, 생활환경 영역으로 측정하고, 분석 결과에 근거한 지역별 정책 우선순위를 제안한다.

## 핵심 이슈 백로그

### M0 — 거버넌스 및 환경

- 저장소 브랜치·PR·릴리스·문서 정책 수립
- Docker 기반 Jupyter/GeoPandas 분석 환경 구성
- 프로젝트 디렉터리와 기본 품질검사 자동화

### M1 — 요구사항 및 데이터 설계

- 공모전 공고·제출 서식·평가기준 확정
- 부산형 IMD 영역·지표·가중치 초안 작성
- 영역별 행정동 데이터 가용성 조사와 대체 규칙 수립

### M2 — 데이터 기반 구축

- 행정동 기준코드와 경계공간정보 확보
- 영역별 원본 데이터 수집과 출처 메타데이터 기록
- 행정동 코드 매칭·결측·단위 표준화 파이프라인 구현
- 데이터 사전 및 품질 리포트 작성

### M3 — 분석 모델

- EDA 노트북과 데이터 품질검사 완성
- 지표 방향성·정규화·영역 점수 계산 구현
- IMD 가중합·순위·10분위 산출 구현
- 가중치와 결측 처리 민감도 분석

### M4 — 해석 및 정책

- 상위 취약지역과 영역별 기여도 분석
- 필요 시 행정동 유형 군집분석
- 부산 특화 환경노출 분석 검토
- 취약유형별 정책 우선순위와 실행 매트릭스 작성
- 1페이지 지도·인포그래픽 초안 제작

### M5~M7 — 제출·릴리스·발표

- 분석보고서와 근거 문서 작성
- 1페이지 시각화 PDF 완성
- 제출 데이터·코드·README 재현성 검증
- v1.0.0 릴리스 및 최종 제출
- 발표자료·데모·질의응답 준비

## 주요 리스크

| 리스크 | 대응 |
|---|---|
| 일부 지표가 구 단위까지만 제공됨 | M1에서 공간 단위와 대체지표를 확정하고 혼합 단위 사용을 원칙적으로 금지 |
| 범죄·소득·고용 데이터 비공개 또는 시차 | 공개 대리지표와 제외 기준을 사전에 문서화 |
| 행정동 명칭·코드 불일치 | 기준연도 행정동 코드 테이블을 단일 키로 사용 |
| 가중치 자의성 | 영국 IMD 가중치를 기준선으로 두고 동일가중·대안가중 민감도 비교 |
| 혼자 진행하면서 검증 누락 | 모든 이슈에 산출물, 검증 방법, 문서 갱신을 완료조건으로 명시 |
