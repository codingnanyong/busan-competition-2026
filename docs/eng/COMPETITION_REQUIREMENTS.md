# 2026 Big Data Competition Submission Requirements

Verified on: 2026-08-11 (KST)

## Sources

- [Competition information and application page](https://www.allforyoung.com/posts/83834)
- Official poster issued by Busan Metropolitan City and Busan Techno Park
- [Official analysis-report template](../templates/2026-big-data-competition-submission-template.hwpx)
- File-upload instructions in the application form

The requirements below were cross-checked against the announcement page, official poster, report template, and application form. No evaluation categories or score allocation were published in the official material available for review.

## Eligibility and schedule

| Item | Confirmed requirement |
|---|---|
| Eligibility | Anyone interested in using data |
| Team size | Individual or team of 1–4 people |
| Track | Track 1: Big-data analysis and visualization |
| Application period | 2026-06-25 through 2026-09-18 17:00 |
| Document-screening result | 2026-09-23 |
| Final presentation | 2026-10-29 |

## Final submission package

Upload one archive containing all of the following files.

| Deliverable | Format | Limit or note |
|---|---|---|
| Data visualization | PDF | One page |
| Analysis report | HWPX and PDF | Both formats required; no more than 10 pages excluding the cover |
| Data used | XLS, CSV, etc. | Data files used in the analysis |
| Final upload | One archive | Maximum 1 GB |

The official material does not specify a filename convention. Recheck the application form immediately before submission. A recommended package layout is documented in the [Korean requirements](../kor/COMPETITION_REQUIREMENTS.md).

Do not redistribute source data when its license prohibits redistribution. Include the provider, source URL, reference date, license, and acquisition method in a source catalog, and submit only redistributable derived data.

## Report contents

- Consent to the collection, use, and third-party provision of personal information
- Overview: problem, background, need, data, tools, methods, process, results, application, and expected impact
- Method: dataset name, format, period, source, preprocessing, validation, analytical procedure, result validation, and visualization
- Results: insights, visualizations, validation, limitations, and improvements
- Application: target area and policy application
- Expected quantitative and qualitative impact
- References
- Evidence for Open Lab or Big-Data Wave bonus points, when applicable

The report outline may be adapted to the analysis. Leave the application number blank and identify the source and contents of any additional private-sector data.

## Pre-submission checklist

- [ ] The visualization PDF is exactly one page.
- [ ] The report is no more than 10 pages excluding the cover.
- [ ] The HWPX and PDF versions contain the same report.
- [ ] Data files and their documentation are included.
- [ ] Every dataset records its source, reference period, and license.
- [ ] Personal data and source data prohibited from redistribution are excluded.
- [ ] The archive opens correctly and is no larger than 1 GB.
- [ ] Only one archive is uploaded to the application form.
- [ ] Schedule, formats, and any new filename rule are rechecked before submission.

## Not published or unresolved

- Evaluation categories and score allocation: not found in the available official material
- Mandatory filename convention: not found in the available official material
- Ownership and public-disclosure terms for submitted work: not confirmed by the available material

These items must not be converted into assumed requirements. Dataset-specific use and redistribution terms are tracked in the COD-10 data-availability audit.
