# v0.8.2 — Linear project attach and docs language folders

## Repository automation

- The Linear issue-creation workflow attaches new issues to team `COD` and the
  contest project.
- Git workflow and issue-map pages no longer repeat Secrets or branch format;
  they point to the integrations guide.

## Documentation layout

- Korean prose lives under `docs/kor/`. English counterparts live under
  `docs/eng/`.
- Language-neutral audit CSVs and checksum JSON stay in `docs/data/tables/` and
  `docs/data/manifests/`.

## Interpretation limits

- Results are an experimental relative screening of living conditions within Busan,
  not official statistics or a statutory funding rule.
