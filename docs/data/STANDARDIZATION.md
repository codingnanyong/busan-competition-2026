# 2025 행정동 데이터 표준화와 검증

## 목적

수집 원본을 SGIS 2025년 부산 행정동 206개 경계와 결합해, 후속 지표 설계에서 사용할
후보 프로파일을 만든다. 이 산출물은 곧바로 IMD 종합점수를 의미하지 않는다. 시점과
직접지표가 아니어도 전 부산 범위와 공간결합 검증을 통과한 자료는
`provisional_scoring_proxy`로 사용하고, 기준일이나 공간단위가 맞지 않는 자료만
`validation_only`로 유지한다.

## 실행

저장소 루트에서 다음 명령을 실행한다.

```bash
docker compose run --rm jupyter python -m busan_imd.processing.standardization
```

학교·생활인구·대기질·버스 후보의 선행 가공은 다음 명령으로 재현한다.

```bash
docker compose run --rm jupyter python -m busan_imd.processing.candidate_processing --collect-coordinates
```

생성물은 다음과 같다.

- `data/processed/standardized/2025/busan_admin_dong_candidate_profile_2025.csv`
  - Git에서 제외되는 재현 가능 가공자료
- `data/processed/standardized/2025/standardization_report.json`
  - 가공자료와 함께 생성되는 보고서 사본
- `docs/data/manifests/STANDARDIZATION_REPORT_2025.json`
  - Git으로 추적하는 검증·출처 보고서

## 표준화 규칙

1. 기준 공간은 SGIS 2025년 부산 행정동 206개, 기준 좌표계는 `EPSG:5179`이다.
2. 행정동 코드 자료는 코드 형식, 중복, 기준 경계 포함 여부와 206개 동 완전성을 검사한다.
3. 시설·정류소 자료는 원 좌표계를 기록하고 `EPSG:5179`로 변환한 뒤 `within` 공간결합한다.
4. 원본의 결측값은 결측으로 남긴다. 정상적으로 결합된 전수형 위치자료에서 해당 동에
   시설이 없을 때만 관측된 0으로 기록한다.
5. 인구 대비 시설 수는 2025년 12월 31일 주민등록인구를 분모로 계산한다.
6. 입력 파일 경로와 SHA-256을 보고서에 기록해 같은 원본으로 재현했는지 확인한다.

## 현재 분석 역할

- 주 분모: 2025년 주민등록인구
- 잠정 점수 대리지표: 2024년 사업체·직장 종사자, 버스정류소, 병원·의원·약국,
  방범 CCTV, 무더위쉼터, 학교 접근성, 2025 대기오염 노출 보간값
- 검증 전용: 혼합 기준일 독거노인, 기준일을 확인하지 못한 AED 현재현황,
  2025 생활인구 서비스수요 맥락

잠정 대리지표는 직접 결과값으로 해석하지 않고 별도의 대리지표 점수로 산출한다.
직접지표가 추가되면 대체 전후 순위 민감도를 비교한다.
