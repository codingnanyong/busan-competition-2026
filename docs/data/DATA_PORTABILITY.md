# 2025 데이터 재수집 및 장치 간 이전 정책

## 원칙

2025 부산 행정동 IMD는 동일 기준기간의 재현을 우선한다. 과거 연도·기간을 요청할 수 있는
API와 공개 페이지는 Mac에서 자동 수집한다. 실행일 현재 상태만 반환하거나 수동으로 받은
파일은 2025 원본 번들을 Google Drive에 보존한다. API 키와 `.env`는 번들에 포함하지 않는다.

Google Drive 보관 경로:

`내 드라이브/Developer/Project/busan-competition-2026/raw-data/2025/`

## 자동 재수집

| 데이터 | 방법 | 자동화 판단 |
|---|---|---|
| 2025 SGIS 행정동 경계 | SGIS API | 연도 파라미터로 재현 가능 |
| 2024 SGIS 사업체·종사자 | SGIS API | 2025 분석의 1년 시차 자료로 재현 가능 |
| SGIS 인구·가구 및 NEIS 학교 | SGIS·NEIS API | 기준연도 및 설립일 필터 재현 가능 |
| 2025 병원·의원·약국 후보 | 공공데이터포털 API | 인허가일·폐업일로 2025-12-31 상태 재구성 |
| 교통사고 통계·다발지역 | KOROAD API | 요청 연도 고정 가능 |
| 2025 경찰 5대 범죄 | 공공데이터포털 파일 API | 버전이 명시된 2025 파일 조회 |
| 2024 SGIS 노후주택 프록시 | SGIS API | 기준연도 고정 가능 |
| 2025 소방서별 화재 요약 | 소방청 API | 발생일 범위 고정 가능 |
| 2025 HEIS 대기질 | 공개 과거 조회 페이지 | 연·월 고정 조회 가능 |

```bash
python -m scripts.bootstrap_data collect-network
```

## Google Drive 원본이 필요한 자료

| 데이터 | 보존 이유 |
|---|---|
| 2025-12 주민등록인구 16개 구·군 파일 | MOIS 화면에서 수동 다운로드 |
| 소비매출 원본 Excel과 파싱 CSV | 부산 데이터 플랫폼의 보호 다운로드 |
| 기초생활보장 보조 원본과 기타 감사 파일 | 고정 URL 또는 과거 버전 재현이 불안정 |
| 분석에 사용한 AED·버스정류소·도시공원 | API가 현재 목록만 반환하여 과거 상태 재조회 불가 |
| 마을버스·독거노인 응답 | API 기준일이 혼합되거나 현재 상태만 제공 |
| 수동 확보 버스정류소 ZIP | 다운로드 당시 기준일을 보존해야 함 |
| 학교·대기측정소 좌표 보조 파일 | 지오코딩 결과를 동일하게 재현하기 위한 고정 입력 |

원본 번들은 `scripts/data_bundle.py`가 `data/raw`만 포함하도록 만들며 `.env`, API 키,
`data/processed`는 포함하지 않는다. 가져올 때 경로 이탈과 심볼릭 링크를 차단하고, 함께
보관한 SHA-256 값으로 파일 무결성을 확인한다.

## Mac 초기화 순서

```bash
cp .env.example .env
# .env에 API 키와 필요 시 BUSAN_IMD_RAW_BUNDLE 입력
python -m scripts.bootstrap_data prepare
```

`prepare`는 고정 번들을 복원한 다음 가공물을 재생성한다. 과거 기준기간이 API에서 계속
제공되는지 확인하거나 원본을 갱신하려는 경우에만 별도로 `collect-network --refresh`를
실행한다.
