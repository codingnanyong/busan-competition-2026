# 데이터 기준기간 정책

## 확정 결정

- 분석 컷오프: **2026-07-31**
- 공간 기준: **SGIS 2025년 부산 행정동 206개**
- 원칙: 컷오프까지 확보 가능한 최신 자료를 사용하되 관측기간 유형과 시차를 공개한다.

공모전 분석은 2026년 7월까지 공개·확보 가능한 자료를 최대한 활용한다. 다만 부분연도
누계와 완결연도 값은 직접 비교할 수 없으므로 동일 지표 안에서는 부산 전 지역에 같은
관측창을 적용한다.

## 지표 선택 규칙

1. 관측 종료일이 2026-07-31 이하인 가장 최신 자료를 우선한다.
2. 연간 지표는 가장 최근 완결연도인 2025년 자료를 우선한다.
3. 월별·분기별·기준일 지표는 2026년 7월까지 사용할 수 있다.
4. 같은 지표의 모든 행정동에는 동일한 시작일과 종료일을 적용한다. 2026년 1~7월 누계와
   2025년 연간값을 같은 열에서 비교하지 않는다.
5. 최신 자료가 없으면 가장 가까운 과거 완결기간을 사용하고 실제 `reference_period`,
   기간 유형(`annual`, `partial_year`, `snapshot`)과 시차(`lag_months` 또는 `lag_years`)를
   기록한다.
6. `published_at`, `reference_period`, `retrieved_at`을 구분하며 게시일만으로 최신성을
   판단하지 않는다.
7. 여러 해 평균은 종료일이 컷오프 이하인 고정 구간만 허용하고 구간을 명시한다.
8. 기관 자료 요청은 가능하면 2025년 연간값과 2026년 1~7월 또는 2026-07-31 기준값을
   함께 요청한다.

## 공개 규칙

결과 표와 지도에는 공간 기준연도와 함께 지표별 관측기간과 기간 유형을 표시한다. 오래된
자료와 부분연도 자료에는 시차·부분기간 경고를 붙이고, 순위 영향을 민감도 분석에서
확인한다. 수집일은 출처 추적용이며 관측기간을 대신하지 않는다.
