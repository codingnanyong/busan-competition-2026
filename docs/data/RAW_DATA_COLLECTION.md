# 원본 데이터 수집과 출처 기록

## 2026-08-12 수집 결과

COD-12는 직접 다운로드 10개와 인증 API 4개, 총 14개 원본을 로컬에 보존하고
[RAW_DATA_MANIFEST.json](RAW_DATA_MANIFEST.json)에 출처와 검증 정보를 기록한다.

| 구분 | 데이터셋 | 건수 | 컷오프 판정 |
|---|---|---:|---|
| 직접 다운로드 | 기초생활보장 5개 구, 빈집 2개 구, 무더위쉼터, 대기측정망, 침수흔적 | 10개 파일 | 사용 가능 10 |
| SGIS API | 2024 사업체·종사자 | 206개 행정동 | 사용 가능 |
| 부산 버스 API | 정류소 | 8,790 | 관측 기준일 확인 필요 |
| 부산 AED API | 자동심장충격기 | 1,079 | 관측 기준일 확인 필요 |
| 부산 대기질 API | 시간별 측정값 | 1,184 | 제외: 2026-08-11~12 |

`사용 가능`은 기준기간이 2026-07-31 이하라는 뜻이며 지수 포함을 자동 승인하지 않는다.
공간범위, 정의, 직접/대리 적합성 및 재배포 조건을 포함한 A/B 게이트는 별도로 통과해야
한다. 버스와 AED는 API가 레코드별 관측 기준일을 제공하지 않아 점수 산정 전 확인이
필요하다. 실시간 대기질 스냅샷은 컷오프 밖이므로 출처 감사용으로만 보존한다.

## 저장 구조

```text
data/raw/
├── audit/                         # 직접 다운로드 10개
├── collection/                    # API 응답 4개와 로컬 manifest
│   ├── EMP-SGIS-001/
│   ├── ENV-AIR-REALTIME-001/
│   ├── HLT-AED-001/
│   ├── HOU-BUSSTOP-API-001/
│   └── manifest.json
└── sgis/admin_boundaries/2025/    # COD-11 기준경계
```

`data/raw`는 Git에서 제외된다. 저장소에는 비밀값이 제거된
`docs/data/RAW_DATA_MANIFEST.json`만 커밋하며, 각 항목에 다음을 기록한다.

- 제공기관과 공식 원문 페이지
- 비밀 쿼리를 제외한 API 엔드포인트와 요청 파라미터
- 관측기간, 기간 유형, 수집시각과 2026-07-31 컷오프 판정
- 이용허락 또는 이용정책
- 로컬 상대경로, 파일 크기, 레코드 수와 SHA-256
- 점수 사용 전 필요한 제한사항

## 실행

최상단 `.env`에 다음 값이 있어야 한다. 실제 값은 Git, 문서, Slack 또는 Linear에 넣지
않는다.

```dotenv
SGIS_CONSUMER_KEY=...
SGIS_CONSUMER_SECRET=...
DATA_GO_KR_SERVICE_KEY=...
```

```powershell
$env:PYTHONPATH = "src"
python -m busan_imd.raw_collection
```

수집기는 다음 검사를 모두 통과해야 manifest를 쓴다.

1. 직접 다운로드 10개의 SHA-256이 감사 원장과 일치한다.
2. SGIS 사업체 응답은 2024년 부산 행정동 206개 코드가 유일하다.
3. 공공데이터포털 응답코드는 성공이고 `totalCount`와 실제 항목 수가 일치한다.
4. manifest의 데이터셋 ID는 유일하고 인증키·access token을 포함하지 않는다.
5. 존재하는 모든 로컬 원본의 SHA-256이 manifest와 일치한다.

API는 갱신되므로 다시 실행하면 응답 건수와 체크섬이 달라질 수 있다. 갱신 결과는 자동으로
이전 자료를 덮어쓰므로, 기준 스냅샷을 바꿀 때만 실행하고 변경 사유와 수집시각을 PR에
기록한다.

## 아직 원본이 없는 후보

- KERIS 학교기본정보 외부 다운로드
- LOCALDATA 병원·약국 전국 파일
- 부산 버스정류소 SHP 파일(API XML 원본은 확보)
- TAAS 교통사고 원자료

이 자료들은 감사 원장에 `not_collected`로 유지한다. 외부 다운로드 경로·재배포 조건 또는
재현 가능한 추출 방법을 확인하기 전에는 확보된 것처럼 표시하지 않는다. 현재 14개 원본만
COD-12 기준 스냅샷으로 본다.

## 출처 원칙

인증키가 없는 직접 다운로드도 API와 동일하게 제공기관, 원문 URL, 관측기간, 수집일,
이용조건, 파일 크기, 레코드 수와 SHA-256을 기록한다. 파일명이나 포털 게시일만으로
관측기간을 추정하지 않는다.
