42개 데이터셋은 모두 출처와 상태를 관리하지만, 공간단위·기준기간·완전성 검증을 통과한
자료만 점수 후보가 된다.

## 카테고리 평가 보조지표

- `TRN-BUSAN-ROUTE-USAGE-2025-001`의 333개 노선 이용량과
  `TRN-BUSAN-BIMS-CURRENT-001`의 290개 현재 노선·22,408개 경유 정류소를 결합했다.
- 노선번호가 일치한 278개를 2025 정류소 ID·좌표에 연결해 204개 동의
  `수요가중 버스노선 접근성`을 생성했다.
- 대중교통 카테고리에서 정류장 공급 60%, 수요가중 노선 접근 20%, 현재 BIMS
  첫·막차와 평시 배차간격 기반 서비스 기회 20%를 적용한다.
- 노선별 2·3통행과 청소년·어린이 구성은 연결 노선 참고값으로, 2023 정류장 승하차의
  출퇴근·심야 비율은 과거 수요 검증값으로만 공개한다.
- 현재 노선망은 2025 당시 노선망이 아니므로 주 B-IMD 종합점수에는 넣지 않는다.

## 검증·맥락 전용

아래 자료는 받은 자료를 버린 것이 아니라 결과의 방향과 총량을 검증하는 데 사용한다.
행정동 직접 점수에는 넣지 않는다.

- `SAF-TAAS-001`: 구·군 교통사고 통계와 다발지역
- `SAF-BUSAN-POLICE-CRIME-001`: 경찰서 관할 5대 범죄
- `DEM-BUSAN-LIVING-001`: 거주·직장·방문, 연령 구성과 주간 서비스 압력 생활인구
- `TRN-BUSAN-VILLAGE-BUS-001`: 구·군 마을버스 공급 맥락
- `SOC-BUSAN-ELDERLY-ALONE-001`: 기준일 혼합 검증 및 소득 추정 설명변수
- `SAF-BUSAN-POLICE-TREND-001`: 부산 전체 교통사고 추세
- `SAF-BUSAN-RISK-AREA-001`: 사고위험지점 공간 검증
- `TRN-BUSAN-BOARDING-2023-001`: 과거 승하차 수요 패턴
- `SAF-NFA-FIRE-SUMMARY-001`: 소방서 단위 화재 총량
- `HLT-AED-001`: 기준일 미확인 현재 설치 위치
- `ECO-BUSAN-CONSUMER-SALES-2025-001`: 가맹점 소재지 소비활동
- `ENV-CITY-PARK-001`: 현재 등록부 기반 도시공원 접근성 맥락

## 직접 점수에서 제외 또는 보류

- 영도구·수영구 빈집: 부산 전역 동일 정의가 아님
- 2026년 실시간 대기질: 분석 컷오프 이후 자료
- 사상구 침수흔적: 부산 전체가 아닌 9개 구역
- 2026년 HEIS 대기질: 2025년 주 분석과 혼합하지 않고 보조자료로만 보관
- SGIS 2024 인구·가구: 2025년 주민등록 분모가 있으므로 대체하지 않음
- 버스정류소 API 중복본: 날짜가 명시된 파일 원본을 우선 사용

따라서 “모든 자료를 점수에 강제로 포함”하지 않는다. 모든 자료는 감사 목록에 남기되,
점수·추정 입력·검증·제외 중 하나의 용도로 명시한다.

## 수집 권한 확보 이후 재검토 (2026-08-26)

공개 API·파일 접근 권한이 열려도 **공간단위·기준일·정의가 맞지 않으면 종합점수에
넣지 않는다.** 지금 막혀 있는 항목의 대부분은 키 부재가 아니라 이 포함 게이트다.

### 이미 점수·보조평가·화면에 쓰는 자료

카테고리 평가와 대시보드가 이미 소화한 자료는 다시 점수에 중복 투입하지 않는다.

- 잠정 점수: 추정 기초생활, 사업체·종사자, 학교 거리·수·교원, 병원·의원·약국,
  노후주택, 버스정류장, 수요가중 노선 접근, 현재 배차 서비스 기회, 교통사고
  다발지점, CCTV, PM2.5, 무더위쉼터, 독거노인(폭염 수요 30%)
- 점수 제외 참고: 생활인구, 소비매출·업종, AED, 도시공원, PM10·NO₂·O₃,
  대기 보간 불확실성, 구·군 사고통계, 야간버스·2023 승하차

### 키가 있어도 기관 집계가 필요한 항목

다음이 확보되면 대리지표를 교체한다. 공개 포털 키만으로는 만들 수 없다.

1. 206개 동 동일 정의 2025-12 기초생활 관측값
2. 거주지 기준 고용·실업
3. 행정동별 2025 범죄·전체 교통사고·화재 건수
4. 거주지 기준 건강결과·교육성과
5. 전역 동일 정의 빈집·과밀
6. 2025 당시 노선망·정류소별 실제 운행횟수
7. 2025-12-31 AED 보관본

국토부 건축물대장 API는 노후주택 후보를 보강할 수 있으나 법정동 주소를 2025 행정동에
결합해야 하고, 현재 수집기는 없다. 신청이 열려 있으면 별도 수집·품질검사 후에만
`HOU-SGIS-OLD-001`을 대체한다.
