# 데이터 카탈로그

이 문서는 부산형 다중박탈지수(B-IMD)의 데이터 후보를 관리한다. COD-10 감사 결과의 행 단위 원장은 [DATASET_AUDIT.csv](DATASET_AUDIT.csv)이며, 이 문서는 판단 근거와 사용 규칙을 설명한다.

## COD-10 감사 결과

- 감사일: 2026-08-11
- 등록 후보: 20개
- 실제 원본 검증: 직접 다운로드 10개와 인증 API 4개(파일 크기, 레코드 수, SHA-256 확인)
- 현재 `include`: 0개
- 결론: 공개 후보는 존재하지만, 동일 기준연도·동일 행정동 경계로 부산 전역을 비교할 수 있는 7영역 기본 지표 세트는 아직 구성되지 않는다.

부산시 행정 읍·면·동 페이지는 표 제목에 205라고 쓰면서 구·군별 행 수의 합은 206이다. COD-11의 SGIS 2025년 동일 응답에서 행정동 코드와 경계가 각각 206개로 일치했으므로 프로젝트 기준지리는 206개로 확정한다. 세부 내용은 [행정동 기준코드와 경계](ADMIN_BOUNDARIES.md)를 따른다.

분석 데이터의 컷오프는 2026-07-31이다. 연간 지표는 2025년 완결자료를 우선하고 월별·분기별·기준일 자료는 2026년 7월까지 사용할 수 있다. 같은 지표 안에서 부분연도 누계와 연간값을 섞지 않으며 게시일·관측기간·수집일을 분리한다. 세부 선택 규칙은 [데이터 기준기간 정책](REFERENCE_PERIOD_POLICY.md)을 따른다.

## 영역별 판정

| 영역 | 확인한 대표 자료 | 등급 | 결정 | 핵심 사유 |
|---|---|---:|---|---|
| 소득 | 5개 구 기초생활보장 수급자 CSV | C | 제외 | 2024~2026 기준일과 급여 분류가 다르고 5개 구만 공개됨 |
| 고용 | SGIS 2024 사업체·종사자 API | C | 보류 | 206개 동을 확보했으나 사업장 고용은 거주자 고용이 아님 |
| 교육 | KERIS 학교기본정보 | B | 보류 | 주소로 접근성 계산은 가능하나 성인 학력·교육성과를 측정하지 않음 |
| 건강 | LOCALDATA 병원·약국, AED API | B | 보류 | AED 1,079건을 확보했으나 기준일 미제공이며 시설 접근성은 건강결과가 아님 |
| 안전 | TAAS 웹 GIS | D | 검증 전용 | 재현 가능한 원본 추출과 파생물 재배포 조건을 확인하지 못함 |
| 주거·서비스 | 영도·수영 빈집, 부산 버스정류소 | B~C | 보류/제외 | 정류소 8,790건은 기준일 확인·공간결합 필요, 빈집은 2개 구만 있고 정의도 다름 |
| 생활환경 | 무더위쉼터, 대기측정망, 실시간 대기질, 사상구 침수흔적 | B~C | 보류/제외/검증 전용 | 실시간 응답은 컷오프 밖이고 나머지도 공간결합·보간 또는 범위 보완이 필요 |

`A` 등급이 없는 것은 실패가 아니라 감사 결과다. 결측 구역을 0으로 채우거나 구 단위 값을 모든 동에 반복하면 비교 가능한 것처럼 보이지만 지수의 의미가 훼손된다.

| 빈집 | 영도 11동과 수영 10동은 각 구 안에서는 완전하지만, 빈집 등급 정의가 서로 달라 시 전체 결합에서 제외 |
| 무더위쉼터 | 1,789행, 좌표 결측 0%. 운영시간·수용인원·냉방성능은 제공하지 않음 |
| 대기측정망 | 37행, 고유 측정소명 34개. 이 파일에는 좌표가 없어 별도 위치 자료가 필요 |
| 사상구 침수흔적 | 9행. 2024년 이전 자료가 없다고 명시되어 검증용으로만 유지 |
| SGIS 사업체 | 2024년 부산 206개 행정동, 코드 중복 0, 사업체·종사자 셀 결측 0% |
| 버스정류소 API | 8,790건 전량 수집. 기준일 미제공으로 컷오프 적합성 확인 전 보류 |
| AED API | 1,079건 전량 수집. 기준일 미제공으로 컷오프 적합성 확인 전 보류 |
| 실시간 대기질 API | 1,184건은 2026-08-11~12 관측으로 2026-07-31 컷오프 밖이라 제외 |

원본 파일은 `data/raw/audit/`에 두며 Git에 커밋하지 않는다. 카탈로그의 SHA-256은 다음 명령으로 재검증한다.

```powershell
$env:PYTHONPATH = "src"
python -m busan_imd.data_catalog docs/data/DATASET_AUDIT.csv --raw-dir data/raw/audit
```

## 기록 및 결측 규칙

- `0`: 제공기관이 해당 단위와 기간에 0건이라고 관측한 값
- `missing`: 수집은 했지만 셀 값이 비어 있거나 파싱할 수 없는 값
- `uncollected`: 공개됐지만 아직 원본을 수집하지 않은 자료
- `private/unavailable`: 비공개, 승인 거절, 지도 열람 전용 등 재현 가능한 원본이 없는 자료
- `not_applicable`: 지표 정의상 해당 단위에 적용되지 않는 값

이 상태들은 서로 대체하지 않는다. 특히 미수집·비공개·해당 없음은 0으로 바꾸지 않는다.

## 공간 결합 규칙

1. 행정동 코드는 같은 기준시점의 행정기관 코드 원장을 우선 사용한다.
2. `제1동`/`1동` 같은 명칭 차이는 구·군 코드와 함께 명시적 매핑표로 관리한다.
3. 법정동은 검증된 법정동-행정동 대응표로만 변환하고 일대다 관계는 인구 또는 면적 가중 규칙을 공개한다.
4. 좌표 자료는 좌표계와 경계 기준일을 기록한 뒤 point-in-polygon으로 결합한다.
5. 집계구는 교차 면적 또는 인구 가중치를 사용하며 매핑률과 미매핑 건수를 공개한다.
6. 구·군 단위 값을 소속 행정동에 반복 배분하지 않는다.

## 추가로 필요한 접근 정보

- 현재 SGIS와 공공데이터포털 키는 로컬 `.env`에 준비되어 있다.
- 2026년 7월 이하 관측기간을 제공하는 기관 담당 창구와 자료별 재배포 조건은 추가 확인이 필요하다.

비밀값은 대화나 문서에 붙여 넣지 않고 로컬 `.env`에만 저장한다. 키가 없어도 공개 CSV 감사와 기관 데이터 요청은 계속할 수 있다.
