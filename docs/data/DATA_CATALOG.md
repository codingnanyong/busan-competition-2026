# 데이터 카탈로그

이 문서는 부산형 다중박탈지수(B-IMD)에 검토되는 모든 데이터셋의 단일 목록이다. 공개데이터로 구현 가능한 최소 모형과 향후 기관 협력으로 대체할 직접지표를 함께 관리한다.

## 기록 원칙

- 데이터셋을 지수에 포함하기 전에 출처, 기준연도, 공간 단위, 라이선스와 갱신 주기를 기록한다.
- 직접지표와 대리지표를 구분하고 대리지표가 대신 측정하는 개념을 명시한다.
- 행정동 코드로 직접 연결할 수 없는 좌표 자료는 사용한 지오코딩·공간결합 방법을 기록한다.
- 확보되지 않은 값과 관측값 `0`을 구분한다.
- 원본 파일은 수정하지 않고 체크섬과 수집일을 남긴다.

## 카탈로그 스키마

| 필드 | 설명 |
|---|---|
| `dataset_id` | 저장소 내부 고유 ID |
| `domain` | 소득·고용·교육·건강·안전·주거/서비스·생활환경 |
| `indicator_candidate` | 연결되는 후보 지표 |
| `measure_type` | `direct`, `proxy`, `context`, `validation` |
| `provider` / `source_url` | 제공기관과 원문 URL |
| `reference_period` | 실제 관측 기준일 또는 기간 |
| `release_date` / `update_cycle` | 공개일과 갱신 주기 |
| `spatial_unit` | 집계구·행정동·법정동·시군구·좌표 등 |
| `format` / `access_method` | CSV·SHP·API·WMS 및 인증 방식 |
| `license` | 이용허락과 재배포 조건 |
| `coverage` / `missing_rate` | 부산 행정동 포함 범위와 결측률 |
| `availability_grade` | 가용성 A~D |
| `decision` | `include`, `hold`, `exclude`, `validation-only` |
| `fallback` | 미확보 시 대체지표 또는 영역 제외 규칙 |
| `collected_at` / `checksum` | 수집일과 원본 무결성 값 |

## 후보 데이터 등록 현황

이 표는 데이터 구조를 먼저 고정하기 위한 작업 목록이다. 실제 URL·기준연도·결측률·라이선스는 COD-10 감사에서 검증한 뒤 확정한다.

| 영역 | 우선 후보 | 유형 | 현재 판단 | COD-10 확인사항 |
|---|---|---|---|---|
| 소득 | 기초생활보장 급여 수급자 비율 | 대리 | 부분 가능 | 부산 전체 행정동의 동일 기준 자료 여부 |
| 고용 | 거주자 고용·실업 또는 사업체·종사자 변화 | 직접/대리 | 부분 가능 | 거주지 기준 자료 확보 여부와 사업장 지표의 한계 |
| 교육 | 성인 저학력 비율 또는 교육서비스 접근성 | 직접/대리 | 부분 가능 | 최신 학력 자료의 공간·시간 범위 |
| 건강 | 건강결과 또는 의료취약 인구·시설 접근성 | 직접/대리 | 부분 가능 | 소지역 건강결과 공개 여부와 최소 셀 기준 |
| 안전 | 범죄·사고·화재 또는 안전 인프라 | 직접/대리 | 부분 가능 | 원시 집계자료 이용 가능성과 WMS 전용 여부 |
| 주거·서비스 | 노후주택·빈집·대중교통·필수시설 접근성 | 직접 | 가능성 높음 | 좌표 품질과 행정동 공간결합 기준 |
| 생활환경 | 침수·폭염·대기·녹지·경사 노출 | 직접/모형 | 가능 | 공간해상도와 관측소 보간의 불확실성 |
