# 소비매출·도시공원·화재 자료 처리 상태

기준일은 2025-12-31이며, 아래 세 자료는 현재 단계에서 모두 **검증·설명용**으로
관리한다. IMD 직접 점수에는 자동 투입하지 않는다.

## 1. 행정동 업종별 소비매출

- 데이터셋 ID: `ECO-BUSAN-CONSUMER-SALES-2025-001`
- 출처: 부산광역시 부산데이터웨이브
- 원본 기간: 2023-01~2025-12
- 사용 기간: 2025-01~2025-12
- 공간 단위: 결제 가맹점 소재 행정동
- 원본: `data/raw/busan_data_wave/consumer_sales/2025/`
- 행정동 산출물: `data/processed/candidates/2025/consumer_sales_2025.csv`
- 업종별 산출물: `data/processed/candidates/2025/consumer_sales_by_category_2025.csv`
- 연령·시간대 분석 복사본: `data/raw/busan_data_wave/consumer_sales/2025/*_parsed.csv`
- 출처·검증 기록: `docs/data/manifests/CONSUMER_SALES_MANIFEST_2025.json`

2025년 27,181행, 206개 행정동, 11개 업종을 확인했다. 월별 일평균을 단순히 12로
나누지 않고 월 일수로 가중하여 연간 일평균 이용금액과 이용건수를 만들었다.

205개 동은 12개월이 모두 있고 1개 동은 11개월만 있다. 누락 월을 매출 0으로
대체하지 않았으며 `consumer_sales_observed_months_2025`와
`consumer_sales_complete_2025`에 완전성을 기록했다. 원본에서 이름이 비어 있던
포털 코드 `2644059000`은 나머지 205개 명칭과 2025년 공식 206개 행정동 명부를
대조하여 유일하게 남은 강서구 신호동(`21120562`)으로 복원했다.

소비매출은 주민의 소득이 아니라 상점 위치에서 발생한 경제활동이다. 따라서 소득
박탈의 직접 지표로 쓰지 않고 상권 활동과 최종 결과의 방향을 확인하는 검증 변수로
사용한다.

원본 세 파일은 일반 OOXML이 아닌 보안 래퍼가 적용되어 있다. 원본을 보존하고 Excel의
UTF-8 CSV 내보내기로 업종·연령·시간대 분석 복사본을 만들었다. 2025년 연령별 14,826행과
시간대별 59,241행을 206개 동에 결합해 30대 미만·60대 이상 소비건수 비율과 22~05시·
09~17시 소비건수 비율을 점수 제외 참고값으로 생성했다. 시간대 자료는 2개 동 14개
동·월에서 63개 시간대 행이 누락되어 해당 2개 동의 시간대 구성비를 결측으로 유지한다.

재생성 명령:

```bash
python -m busan_imd.collectors.consumer_sales
```

## 2. 도시공원 정보 API

- 데이터셋 ID: `ENV-CITY-PARK-001`
- 출처: [공공데이터포털 전국도시공원정보표준데이터](https://www.data.go.kr/data/15012890/standard.do)
- 수집 방법: 승인된 `DATA_GO_KR_SERVICE_KEY`로 부산 16개 구·군 API 조회
- 원본·정규화 결과: `data/raw/public_data_portal/city_parks/current/`
- 출처·검증 기록: `docs/data/manifests/CITY_PARKS_MANIFEST.json`

API에서 부산 공원 652개를 중복 제거 후 확보했으며 좌표 결측은 0건이다. 652개 모두
공원 지정일이 2025-12-31 이전으로 분류됐다. 다만 이 API는 **현재 등록부**이고
2025-12-31 당시의 보존 스냅샷이 아니다. 지정일이 과거라는 사실만으로 기준일 당시
운영 여부가 완전히 증명되지는 않으므로 공원 접근성의 검증·설명용 자료로 사용한다.

재수집 명령:

```bash
python -m busan_imd.collectors.city_parks --refresh
```

## 3. 소방 자료 구분

이름이 비슷한 세 자료를 혼동하지 않는다.

| 자료 | 기간 | 공간 단위 | 2025 분석 역할 |
|---|---:|---|---|
| `SAF-NFA-FIRE-SUMMARY-001` 소방청 화재정보서비스 | 2025 | 소방서·일 | 부산 전체·소방서 총량 검증 |
| 소방청 화재현황 | 공개 원문 2023-12-31 기준 | 시·도·시·군·구 및 화재 건별 속성 | 과거 구조·원인·피해 검증 |
| 소방청 지역별 화재피해 현황 | 2019-01~2023-12 | 화재 발생 지역 | 과거 공간 패턴 참고만 가능 |

화재정보서비스는 현재 `DATA_GO_KR_SERVICE_KEY`로 실제 호출이 성공했고 2025년 365일
부산 소방서 자료가 이미 수집돼 있다. 다만 발생 주소가 없어 행정동 직접 점수로 쓸 수
없다.

화재현황은 연간 원문을 공공데이터포털이 API로 자동 변환한 서비스다. 현재 공개 원문은
`소방청_화재현황_20231231`이며 전국 115,238행이다. 2026-08-14에 공개 페이지에서
확인한 API 식별자로 실제 호출했으나 HTTP 401 `유효하지 않은 인증키`가 반환됐다.
인코딩키와 디코딩키를 모두 시험했으므로 신규 신청 권한 전파 또는 활용신청 상세의
서비스 URL·키를 다시 확인해야 한다. 접근이 열리더라도 시·군·구와 상세 화재 속성을
제공하는 2023 자료이므로 과거 검증용이다.

지역별 화재피해 API도 활용신청이 완료됐지만 공개 시간범위가 2019~2023년이다. 두
과거 자료를 2025년 행정동별 화재 건수로 추정하거나 직접 점수화하지 않는다. 2025년
안전영역의 직접 화재지표가 필요하면 부산소방재난본부에 동일 정의의 2025년 행정동
집계를 별도로 요청해야 한다.
