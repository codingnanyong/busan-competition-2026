# 필요 데이터 요청 로드맵

COD-10 감사에서 공개자료만으로 직접지표를 만들 수 없거나 부산 전역 비교가 불가능한 항목을 정리한다. 모든 요청은 개인자료가 아닌 비식별 행정동 집계표를 대상으로 한다.

## 사용자가 준비할 것

### 지금 필요한 접근 정보

| 항목 | 용도 | 필수 시점 | 전달 방법 |
|---|---|---|---|
| SGIS consumer key/secret | 사업체·종사자·인구·경계 API의 실제 연도와 범위 확인 | 고용 후보와 경계 감사 전 | 로컬 `.env`에 `SGIS_CONSUMER_KEY`, `SGIS_CONSUMER_SECRET`로 저장 |
| 공공데이터포털 service key | AED·버스·대기 OpenAPI 실제 응답 확인 | 좌표형 대리자료 수집 전 | 로컬 `.env`에 `DATA_GO_KR_SERVICE_KEY`로 저장 |
| 기관 요청 담당 창구 | 아래 직접지표 요청 발송 | 공개자료 기반 최소모형과 병행 가능 | 담당 부서명·공식 이메일만 확인 |

비밀키는 Slack, Linear, GitHub, 문서 또는 대화에 붙여 넣지 않는다. 키가 아직 없어도 공개 CSV 기반 감사와 요청서 초안 작성은 진행할 수 있다.

### 확정된 기준과 아직 필요한 정보

확정: 공간 기준은 SGIS 2025년 행정동 206개, 데이터 컷오프는 2026-07-31이다.

1. 기관 협조자료를 결과물·GitHub·Docker 이미지에 재배포할 수 있는지
2. 비공개 자료를 점수 산출에만 쓰고 원본은 제출하지 않는 방식이 허용되는지
3. 최신 자료가 없는 영역에서 허용 가능한 최대 시차

## 요청서 필수 조건

- 5명 미만 등 소수 셀은 기관 기준에 따라 범주 통합 또는 마스킹한다.
- 이름, 주소, 전화번호, 개인 식별자, 개별 사건 서술은 요청하지 않는다.
- 분모, 중복 제거 규칙, 기준일, 행정동 코드 버전을 함께 요청한다.
- 2025년 연간값과 2026년 1~7월 또는 2026-07-31 기준 집계를 가능하면 함께 요청한다.
- 관측 0, 미수집, 비공개, 해당 없음의 표현 방식을 확인한다.
- 원본 이용허락과 집계·지도·지수 등 파생물 공개 허용 범위를 서면으로 확인한다.
- 제공 불가 시 가능한 최소 공간단위와 불가 사유를 기록한다.

## 수용 판정

자료를 받으면 [DATASET_AUDIT.csv](DATASET_AUDIT.csv)에 새 고유 ID를 부여하고 원본 SHA-256, 기준기간, 공간단위, 매핑률, 결측률, 라이선스를 기록한다. A/B 게이트를 통과하지 못한 자료는 기관 제공 자료라도 종합점수에 자동 포함하지 않는다.

## 단계별 진행

1. COD-11에서 기준 행정동 코드·경계와 인구 분모를 고정한다.
2. 인증키가 준비되면 SGIS와 공공데이터포털 API 응답을 검증한다.
3. 공개 B등급 대리자료로 재현 가능한 최소모형을 구축한다.
4. 위 기관 요청으로 소득·고용·건강·안전 직접지표를 교체한다.
5. 갱신·드리프트·영향평가를 통과한 버전만 정책 참고지표로 승격한다.
