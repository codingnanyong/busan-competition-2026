# 데이터 가용성 매트릭스

이 문서는 후보 지표가 부산 전체 행정동에서 비교 가능한지 판정한다. 현재의 `부분 가능` 평가는 초기 조사 결과이며 COD-10에서 원문 데이터로 재검증한다.

## 가용성 등급

| 등급 | 기준 | 지수 사용 원칙 |
|---|---|---|
| A | 동일 기준연도·행정동 직접 통계, 전체 범위와 이용조건 확인 | 우선 포함 |
| B | 좌표·집계구·법정동 자료를 검증된 방식으로 행정동 집계 가능 | 변환과 오차를 기록하고 포함 가능 |
| C | 과거연도·일부 구군·대리지표 또는 공간 단위가 불완전 | 민감도 분석용 또는 보류 |
| D | 비공개·열람 전용·재배포 불가·정의 불일치 | 종합점수에서 제외 |

## 초기 영역 판정

| 영역 | 공개데이터형 후보 | 예상 등급 | 핵심 공백 | 현재 모형 원칙 |
|---|---|---:|---|---|
| 소득 | 기초생활보장 수급자 비율 | B~C | 행정동·급여유형·기준연도 통일 | 전체 부산 범위가 아니면 제외 |
| 고용 | 사업체·종사자 증감 | B | 거주자 실업·불완전고용 | `주민 고용박탈`로 과대해석 금지 |
| 교육 | 저학력 또는 교육시설 접근성 | B~C | 최신 성인학력 소지역 자료 | 접근성과 성과를 별도 표기 |
| 건강 | 고령·장애·의료급여·의료접근성 | B~C | 질환·사망 등 건강결과 | 시설 수와 건강상태를 구분 |
| 안전 | 사고·화재·재난·안전 인프라 | B~C | 실제 범죄 발생 집계 | 범죄 대리지표라는 표현 금지 |
| 주거·서비스 | 노후도·빈집·필수시설·교통 접근성 | A~B | 구군별 빈집 정의 차이 | 공통 정의가 있는 지표만 결합 |
| 생활환경 | 침수·폭염·대기·녹지·경사 | B | 공간해상도·보간 오차 | 노출모형과 관측값을 구분 |

## 포함 게이트

후보 지표는 다음 조건을 모두 충족해야 기본 종합점수에 포함한다.

1. 부산 전체 기준 행정동을 같은 정의로 비교할 수 있다.
2. 분자·분모·방향성과 기준기간이 문서화되어 있다.
3. 관측값 `0`, 비공개, 미수집, 해당 없음이 구분된다.
4. 법정동·좌표·집계구 변환의 재현 코드와 매핑률이 존재한다.
5. 결측률과 극단값 처리 결과가 공개된다.
6. 이용허락이 분석 결과와 파생자료 공개를 허용한다.

하나라도 충족하지 못하면 `hold`, `validation-only` 또는 `exclude`로 판정한다. 결측을 0으로 대체해 순위를 계산하지 않는다.

## 시간·공간 정렬

- 하나의 기준연도와 기준 행정동 코드를 먼저 고정한다.
- 기준연도 차이는 지표마다 공개하고 허용 시차를 사전에 정한다.
- 구 단위 값을 소속 행정동에 반복 배분해 종합점수에 사용하지 않는다.
- 경계가 바뀐 자료는 면적비가 아니라 가능한 경우 인구가중 변환을 우선 검토한다.
